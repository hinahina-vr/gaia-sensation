取得日：2026-09-09。公式公開表・GISをGAIA SENSEWAREが照合・加工したローカル保存データです。公的機関による評価・推奨・危険度判定ではありません。

- NITE：[PRTRデータ／事業所GIS](https://www.nite.go.jp/chem/prtr/mapdata/download.html)。2022年度のWGS84座標。
- 国土交通省・国総研：[河川環境データベース](https://www.nilim.go.jp/lab/fbg/ksnkankyo/)。北海道〜九州の9地方、河川の魚類・底生生物の確認リストおよびGIS。ダム・沖縄は含めません。
- 利用条件：[環境省](https://www.env.go.jp/mail.html)、[国総研](https://www.nilim.go.jp/aboutlink.htm)、[NITE](https://www.nite.go.jp/homepage/policy.html)。出典・取得日・加工を展示の出典パネルに明記しています。

環境省・国総研の公共データ利用規約と出典・加工表示を2026-09-09に確認。NITEのサイト全体を公共データ利用規約の対象とは扱いません。[PRTRデータ提供ページ](https://www.nite.go.jp/chem/prtr/mapdata/index.html)は、ダウンロード用データの独自表示・解析・加工を案内しています。この展示では同年度の点データから整理番号と位置の数値を照合に使い、NITEの説明文・写真・ロゴ・地図画像・サイトデザインは転載しません。NITEから個別許諾を取得した、またはNITEが本展示を承認したという表示は行いません。

`manifest.json` に38個の公式ZIPのURL、バイト数、SHA-256、除外件数を記録。原ZIPはGit管理外の `artifacts/prtr-biology-sources/` に保持します。代表者氏名・個人の連絡先は配信用JSONに収録しません。

再生成：`scripts/fetch-prtr-biology-sources.ps1` → Pythonで `scripts/build-prtr-biology-data.py` → `scripts/check-prtr-biology-sources.py` → `node scripts/check-prtr-biology.mjs`。Pythonはlxml、LZH展開にはWindowsのbsdtarを使用。公式配布の実行ファイルは起動しません。元のExcelファイルを変更せず、セル値のみ抽出します。

## PRTRの意味

2022年度の整理番号が一致する32,191事業所を掲載。事業所名は環境省の本紙、座標はNITEの同年度GIS。照合後に全事業所の都道府県・市区町村の一致も検証しています。年度をまたぐ整理番号の同一性は仮定していません。座標を照合できない191事業所は地図から除外。

別紙の単位コード1（kg）のみを合計し、単位コード2（mg-TEQ、ダイオキシン類）3,376行を除外します。大気、水域、土壌、埋立、下水道、事業所外の廃棄物等の6区分は別々に保持。展示65＝大気、66＝水域、67＝下水道＋事業所外の廃棄物等。67の内訳では両者を分けて表示します。

空欄や対象物質がない事業所をゼロへ補完せず、不完全な合計は記録なし。排出量は周辺環境の濃度、毒性で重み付けした量、危険度、基準への適合ではありません。届出対象外排出量、最新年度、現在の稼働状況は表しません。光の上昇・下降・矢印は区分の模式演出で、拡散範囲、風向、経路ではありません。表示色は `log10(1+量)` による対数目盛。

## 生物の意味

2019〜2023年度に絞り、調査管理番号と地区番号で確認リストをGISの地区代表点へ照合。同じ地区・年度の種コードを重複除去して数えます。「確認分類群数」はこの種コード数の展示用表記で、厳密な種数・生息密度・生物多様性指標ではありません。属・科・さらに上位の同定も含みます。

地区ごとの `taxonNames` が表示に使う原表表記です。同一コードに異なる名前がある場合も上書きせず配列で保持し、画面では「 / 」で併記します。名称の訂正や同義語への統一はしていません。データ全体の `taxonNames` はコードごとの最初の表記の索引に過ぎず、個々の地区の表示に使用しません。

魚類は対象83,674行から位置の照合ができない2,093行、底生生物は対象360,690行から11,849行を除外。曖昧な複数座標も無理に採用しません。除外行は生物ゼロではありません。

| 年度 | 魚類の地区数 | 底生生物の地区数 |
| --- | ---: | ---: |
| 2019 | 222 | 213 |
| 2020 | 101 | 209 |
| 2021 | 139 | 97 |
| 2022 | 214 | 142 |
| 2023 | 154 | 177 |

GISの経緯度を保持し、小数7桁で保存。個別の測地系定義ファイルはなく、独自の測地変換は行いません。地区代表点は個体の精密な採集位置や生息範囲ではありません。年度ごとに調査範囲・方法・季節・同定精度が異なるため、確認数の増減を生態系の改善・悪化、絶滅、水質等級、腐水性階級へ変換しません。魚・小さな脚の描画は区分の象徴で、実際の種の外見や個体数を示しません。
