# 日本沿岸のCOD — 保存元データ

出典: [環境省 水環境総合情報サイト / 公共用水域水質測定データのダウンロード](https://water-pub.env.go.jp/water-pub/mizu-site/mizu/download/download.asp)

2026-09-08に、公開フォームと同じダウンロード処理で全国の海域・生活環境項目・年間値（2020〜2024年度）を取得した。ZIP内の `output.csv` はCP932。ZIPは取得時のまま保存し、ファイルサイズ・SHA-256・抽出条件を `manifest.json` に記録した。

| 年度 | 地点記録数 | COD平均値あり | COD平均値欠測 |
| --- | ---: | ---: | ---: |
| 2020 | 2,033 | 2,032 | 1 |
| 2021 | 2,061 | 2,060 | 1 |
| 2022 | 2,009 | 2,008 | 1 |
| 2023 | 2,041 | 2,037 | 4 |
| 2024 | 2,042 | 2,041 | 1 |

`COD` は年度平均値（mg/L）、`COD75` は75%値。元資料の注記列 `COD3` / `COD753` を保持する。空欄・99999は欠測。`ND` や `<` / `>` の注記がある場合は正確な実測値に変換せず、数値をnull、注記を原文として保持する。実データのCOD75には `<0.5` がある。環境基準への適合を年度平均から判定しない。

年度内のシステムID `ZETTAICODE` は年をまたぐ照合に使わない。地点コードは `PREFCODE`（2桁）+ `SUIIKICODE`（3桁）+ `CHITENCODE`（2桁）とする。名称・座標は年度ごとに保持する。欠測・その年度に記録のない地点を前後の年度で補完しない。

座標はCSVのX/Y（経度/緯度）を保持し、元サイトのJGD2000地理座標系を既存の概観用地図へ投影する。測量用の座標変換・精度は保証しない。全国の沿岸測定地点であり、日本のすべての海面を測ったデータではない。日本海側だけに限定したデータでもない。

参照: [年間値ファイルの説明書](https://water-pub.env.go.jp/water-pub/mizu-site/mizu/download/kousui/kousui_y_manual.pdf)、[環境省サイトの利用条件](https://www.env.go.jp/mail.html)。環境省サイトが示す公共データ利用規約1.0に基づき、出典と加工主体を表示する。ロゴ・写真や第三者著作物は取り込んでいない。過去の他資料に対する製作者の公開判断を、この新規データの許可として流用していない。

## 再現

リポジトリのルートで実行する。取得はネットワーク接続を要するが、ビルドと照合は保存ZIPだけを読む。

```sh
node scripts/fetch-japan-marine-cod.mjs
python scripts/build-japan-marine-cod.py
python scripts/build-japan-marine-cod.py --check
python scripts/check-japan-marine-cod.py
```

生成物: `data/japan-marine-cod.json`。元の10,186記録を全件収録し、色域の補間・未観測海域の推定・欠測のゼロ化は行わない。取得スクリプトの対象年度と取得日はこの保存版に固定されている。将来の更新は別の取得日・年度・出典ハッシュを記録して行う。
