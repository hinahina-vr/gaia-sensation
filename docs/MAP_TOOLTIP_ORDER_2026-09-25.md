# 展示ツールチップと展示順の修正

## 依頼と対応

- 原文: 「フォーカスするとツールチップがチラチラするの直したい」「01と02入れ替えたい」「02 火 も 04地震と入れ替えて」「できたらコミットしといて」
- 最終順: **01 風 / 02 地震 / 03 PM2.5 / 04 火 / 05 雲**。06以降は変更しない。
- 番号、実ボタンのDOM順、スマホのタイル、副題、出典の番号、前後移動、URL、再生・巡回の対象を整合させた。データIDとストーリー内の標準モード索引は維持。
- 火災の再生処理を「番号1」という前提から定義の番号による判定へ変更。背景の乱数シードは保持し、番号変更による見た目の変化を防止。
- JSのキャッシュ更新を入口HTMLから対象モジュールの依存関係まで反映。
- ローカルコミットのみ。プッシュ・デプロイは対象外。

## ちらつきの再現と修正

日本の展示一覧で63 LASから64 NPへ80ms間隔でホバー。以前のアンカー用の260msタイマーが残り、64を表示したままX座標が952→862へ戻る現象をChromeで記録した。

修正後は旧タイマー・フレームをキャンセルし、現在のアンカー以外からの位置更新を無効化。最初の描画前にも配置する。同一アンカーへのイベントで内容と配置を再設定しない。マウスとキーボードの判定を同じフレームにまとめ、キーボードフォーカス優先の方針を統一した。

最終記録ではホバー64の位置は952,481、フォーカス63の位置は862,494で安定。素早いフォーカス切替、マウス併用、メニュー外へ移動後の非表示も合格。
