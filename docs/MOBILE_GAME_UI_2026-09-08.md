# スマホ地図UI：展示コレクションと操作デッキ

## 対象

2026-09-08 の「スマホUIが地味。PC版に寄せて、ソーシャルゲームのようにワクワクする感じに」という依頼へのローカル実装。
基点は `3a14ec587a8fb7203b37674c12d95a77c1cf4a78`。公開・push・コミットは行っていない。
先に完了した concept ページの変更は保持し、本作業では変更していない。

## 変更内容

- `map-mobile-shell.js`：30展示をテーマカラーと装飾SVG付きカードに変更。カテゴリへの移動、現在の展示、世界／日本・時間種別・説明を保持。選択は元の展示ボタンに接続し、データ提供元の実ノードは移動しない。
- `map-mobile-shell.css`：PC版に合わせた青い光沢、発光する図柄、選択枠、アイコン付き下部ナビ、操作カード。スマホ2列／タブレット3列。横画面は見出しを圧縮してカード領域を確保。
- 観測パネルの接続状態・観測時刻・数値を維持。重複した大見出しを省き、出典と説明は「読み方・凡例」から読める。小型画面でも火災の数値と再生バーが切れないように配置。
- 統計分析を利用できない展示では、無効状態と理由を明示。出典・統計分析・デモ・ガイド・ズームは元の操作へ接続。
- 入場時の短いアニメーション、押した時の反応。OSの動きを減らす設定に対応。テーマカラーをデータの接続状態や警報の色としては使わない。架空の実績、進捗、LIVE表示は追加しない。
- ポップアップ背景の80%不透明度を維持。文字・アイコンを含む親要素は透過させない。新しい外部画像、依存ライブラリ、通信先は追加していない。
- `gaia-mode-loader.js` / `index.html`：モバイルスタイルの適用順とキャッシュ識別子を更新。
- `package.json`：`check:mobile-game-ui:browser` を追加。

## ブラウザ検証と証跡

Windows上のローカルChrome、スマホ／タッチのエミュレーションで検証。APIは保存データ・合成fixtureを使用しており、実配信の正常性や物理スマホの検証を意味しない。

1. `node scripts/check-mobile-map-shell-browser.mjs http://127.0.0.1:4447 390,320,768,844,1440 all artifacts/mobile-game-ui-regression`
   - 390×844、320×568、768×1024、844×390で30展示ずつ、計120展示の選択・読解パネル・操作パネルを検証。
   - スライダー、出典、統計分析、ガイド再生、デモ開始とユーザー操作による停止、フォーカス循環、Escape、生態系比較パネルの復帰、PC幅への切替、ストーリー専用レイアウトの除外。
   - 横はみ出し、44px以上のタップ領域、地図上のパネル位置を検証。短い画面は数値を切らないため観測パネルの面積上限を1/3、通常の縦画面は1/4とした。
   - 合格後、図柄の対応とアクセシブルな補足説明を仕上げ、横画面の観測パネル高・展示ヘッダーを調整した。そのためこの120展示の証跡は仕上げ前の版であり、ファイルのSHA-256は `artifacts/mobile-game-ui-regression/report.json` に固定している。
2. `node scripts/check-mobile-game-ui-browser.mjs http://127.0.0.1:4447`
   - 最終版の図柄対応、説明、選択状態、実タップ、実タッチスワイプ、末尾の展示と前後循環、出典、利用不可理由、拡大・全体復帰、背景タップ、誤った背景判定の防止、動きを減らす設定を上記4画面で再確認。
   - 火災の観測パネルに数値・スライダーの切れがないことを4画面で確認。
   - 1440×900、1920×1080でHEADと最終版を比較し、PCの主要パネルの位置・大きさ・背景・枠・フォントが一致することを検証。
   - 同一環境・展示・保存データで旧UIも実際に起動し、文字だけのカードを再現。変更前後のスクリーンショットと最終版SHA-256は `artifacts/mobile-game-ui/`。
3. `node scripts/check-mobile-map-shell-browser.mjs http://127.0.0.1:4447 844 all artifacts/mobile-game-ui-landscape-final`
   - 最後にレイアウトを調整した横画面は、最終版で30展示・関連操作を再実行。証跡は `artifacts/mobile-game-ui-landscape-final/`。

最終実行結果は各 `report.json` の `status`、検証ファイルのハッシュは `sha256` を参照。
上記3実行はいずれも `passed`。最終版のJSは `aa01f5b68cb422cc9cd9f944b0c854aba95e22de26dd80bc7493eff6d5d35bc5`、CSSは `776ce405161cf346f81d2ef48ca647f727299333271aef21c84378e26c2d5544`（SHA-256）。最終試験後は実行コードを変更していない。
