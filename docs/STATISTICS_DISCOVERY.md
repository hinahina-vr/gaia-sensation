# データの特徴から、確かめるべき課題へ

2026-09-07 ローカル実装。外部AI呼び出し・APIキー利用・公開・デプロイなし。

「分析」の入口は、共通の要約統計ではなく `discovery`。実際の対象・期間・値から比較候補を探し、課題の候補、意味、観測された根拠、追加の検証、断定できないことを表示する。問いは仮説であり、検証済みの因果効果ではない。

## 保存データから得た例

- 再エネ：ケニアとサウジアラビアは代表地点の日射・風速が近いが、同年の発電割合に大きな差がある。自然条件の良さだけを導入の説明にせず、電源構成・設備・制度を比べる問いへ。国全体の自然条件や政策効果と断定しない。
- 海流：79地点で、速さの平均は約0.28m/s、方向を含めた平均ベクトルの大きさは約0.06m/s。平均の弱さを静かな海と取り違えず、流れが分かれる場所を調べる。疎な格子の探索で、全球の面積加重平均でも漂流予測でもない。
- 人口移動：選択月では11都道府県が転入超過、36都道府県が転出超過。東京の受け入れと福島などの流出を一つの平均で打ち消さず、世代・移動理由・サービス維持の条件を分けて確かめる。直接の移動経路は推定しない。
- 雨量：福島と高知では雨日数が108日と115日だが、年間降水量には2,014mmの差がある。水量の違いが一部の日や季節に集中しているのかを調べる。
- 雨日数：秋田と広島では年間降水量が2,022.5mmと2,026.5mmだが、雨日数には93日の差がある。同じ年合計から同じ屋外活動条件を想定せず、雨の日の配置を確かめる。代表観測地点の値であり県全域の水量や損失ではない。

## 動作と境界

- 集中、近い条件での差、前後の変化速度、複数地点の共通変化、逆向きベクトル、異なる指標の順位の食い違い、正負の移動、地震の震源条件、記録の収録偏りを探索。
- 候補を作る条件と計算を表示する。選択スコアは表示優先順位で、確信度・p値・危険度ではない。
- 選択期間・検索条件に追従し、根拠の国・地点・年の記録へ戻れる。
- 1地点・1時点しかない場合は比較不足を明示し、地域差・平常差・増減を発見扱いしない。
- 補完値は表示対象に含めても特徴探索・国のランキングから除外。カテゴリの行番号を平均しない。人口・排出・FRPなどと、合計して意味のない率・濃度を区別。
- 既存25手法・保存ビューを維持。手法を手動選択した場合の統計的読み取りは別の補足で表示し、課題探索とその手法の結論を混同しない。
- 派生流速・モデル値・出典値の区別と、比較年・代表地点の制約を残す。

## 主要ファイル

- `statistics-discovery.js`：特徴抽出・候補選択・課題の構成。
- `statistics-data-insights.js`：探索結果と既存統計読み取りの分離。
- `statistics-methods.js`、`statistics-lab.js`、`statistics-workspace.css`：入口・表示・根拠レコードへの導線。
- `src/exploration/{planet-statistics,live-statistics,estat-exhibits}.js`：既存データの関連指標を分析へ引き渡す。元の観測値や保存データは変更しない。

## 検証

- `npm run check:statistics-data-insights`：特徴に応じた候補選択、値を変えると候補が消える反例、傾きの数値、時間順、同年条件、補完・欠測・カテゴリ番号・1点データのガード。
- `npm run check:statistics-lab`：既存の計算と適用条件、25手法の互換性、新しい探索入口。
- `node scripts/check-statistics-discovery-browser.mjs`：全30展示の実際の分析ボタン、PC1440px・スマホ390px、問いの表示、対象レコードへの移動。
- `node scripts/check-statistics-data-insights-browser.mjs`：26手法、12データセット×25手法の組合せ、検索・補完・欠測、320〜3840pxの5画面幅、タブとキーボード。
- 実データはリポジトリ内の保存値。全球の天気・大気・地震のブラウザ経路だけは、再現可能な異なる値を持つAPIテストデータを使用。テスト結果を現在の観測事実として公開しない。

画面証跡は `artifacts/statistics-discovery/`。全体チェックは `npm run check`。
