# ライブ展示の取得状態バッジ移動 — 2026-09-09

## 対象と変更

報告された「取得不可」が統計分析ボタンの背後に重なる症状を修正。MAP 15〜20 の状態バッジを、下部ドック右上の絶対配置から「都道府県」見出し横の専用スペースへ移した。見出しとバッジは通常の flex 配置で幅・間隔を確保し、狭い画面でも表示する。取得状態の判定・データ処理・出典リンク・統計分析の利用可否は変更していない。

実装: `src/exploration/live-exhibits.js`、`realtime-exhibits.css`。読み込み更新: `src/exploration/index.js`、`gaia-mode-loader.js`、`index.html`（`status-place-20260909`）。回帰テストと npm コマンドを追加。既存の出典余白テストは、展示数30件固定の古い準備待ちをアプリの準備完了判定に置換し、検証出力先の指定を可能にした。
