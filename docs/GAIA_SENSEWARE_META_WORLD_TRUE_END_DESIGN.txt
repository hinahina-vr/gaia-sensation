────────────────────────────────────────
【メタ世界の核】
────────────────────────────────────────

観客が開いているWebサイトそのものが、
ミズハ、アマネ、サクヤの三人が作っていたコンテスト作品である。

ストーリーモードは過去を再生する映像ではない。
残ったチャット、操作履歴、公開データ、二人の記憶を、
ブラウザ上でその都度組み直している。

観客が最初に画面へ触れた時点で、再生だけの状態は終わる。
以後の操作はVISITOR TRACEとして作品へ加わる。

一周目の観客は、自分が物語を見ていると思っている。
実際には、三人目の空席へ座り、未完成だった提出物を動かしている。


────────────────────────────────────────
【絶対に変えない事実】
────────────────────────────────────────

1. サクヤは実在した人間である。

AI、共同アカウント、架空人格、未来の観客ではない。
ここをひっくり返すと、三人の関係と喪失が安くなる。

2. サクヤが来なかった理由は明かさない。

事故、病気、失踪、家庭事情、自死など、原因を確定しない。
二人が持っていない情報を、作品側だけが暴露してはいけない。

3. 02時14分の投稿は本人が送った。

「入力中 4.8秒」も実在する操作記録。
ただし、入力していた文字列は保存されていない。

4. 補完された候補文は本人の文ではない。

トゥルーエンドでもSOURCEへ昇格しない。
よく似ていてもDERIVEDのまま。

5. サクヤは自分の不在を予知していない。

遺言として仕組んだのではない。
制作方針として、以前から「最後の入力欄を観客へ渡す」設計を進めていた。
その作業だけが、結果として不在のあとに残った。

6. トゥルーエンドでもサクヤは戻らない。

新着メッセージ、隠し音声、実は生きていたという通知は出さない。


────────────────────────────────────────
【四つの層】
────────────────────────────────────────

LAYER 0：公開サイト

コンテストへ提出されたGAIA SENSEWARE。
観客が現実に開いているページ。

通常のトップ画面では、この層を意識させない。
トゥルーエンド直前にだけ、ファイル名、バージョン、操作記録が見える。


LAYER 1：三人の物語

オンラインサークル「惑星の放課後」。
初めて会う約束。
逗子駅の青りんご。
来なかったサクヤ。
三か月後の公開前夜。

一周目は、ここが物語の全体に見える。


LAYER 2：データの出自

SOURCE
実際に観測、保存、送信されたもの。

DERIVED
計算、近似、補完、解釈で作ったもの。

SCENARIO
条件を変えた試算と、観客の操作から生まれたもの。

この三分類はデータ表示の規則であり、物語世界の規則でもある。

サクヤの最後の投稿はSOURCE。
4.8秒の長さもSOURCE。
候補文はDERIVED。
観客が残す文はSCENARIO。


LAYER 3：書き込み権限

サクヤが最後に作業していた層。

彼女が変更したのは文章ではない。
最後の入力欄を誰が使えるか、という設定だった。

変更前

final_line_owner = SAKUYA
final_line_required = true
visitor_mode = replay_only

変更後

final_line_owner = VISITOR
final_line_required = false
visitor_mode = write_trace

この差分が、トゥルーエンドで初めて表示される。


────────────────────────────────────────
【ブラウザそのものを使うメタ演出】
────────────────────────────────────────

作品の外に見える操作を、一部だけ物語へつなぐ。

アドレスバー

大学前のコンテスト告知に載っているURLと、
観客が開いているURLを同じにする。

ローカル確認時は一致演出を出さない。
公開サイトだけで成立するヒントにする。


戻る操作

一周目の「戻る」は普通の画面遷移。
一度エンディングを見たあとは、戻った先に前回のVISITOR TRACEが薄く残る。

ブラウザの履歴を壊さない。
戻るボタンを奪わない。


再読み込み

再読み込みしてもSOURCEと閲覧済みエンディングは変わらない。
操作途中のSCENARIOだけ消える。

消えた直後、画面の隅へ一秒だけ表示する。

SCENARIO CLEARED
SOURCE UNCHANGED


VIEW SOURCE

本物のブラウザ開発者ツールを必須にはしない。
作品内のSOURCE表示だけでトゥルーエンドへ到達できる。

ただしHTMLソースを自分で開いた人への小さな印は置いてよい。

<!-- final field may stay empty -->

これを解除条件には使わない。


現在時刻

トゥルーエンドのVISITOR投稿に、端末の現在時刻を使う。
サクヤの02:14と同じ書式で並べる。

日時は表示だけに使う。
サーバーへ送らない。


タブ名

通常：GAIA SENSEWARE

MODE 07で4.8秒待った直後：GAIA SENSEWARE (1)

新着メッセージのように見えるが、ページへ戻ってもサクヤの投稿は増えていない。
増えているのはVISITOR TRACEの未確認項目。

トゥルーエンド後：GAIA SENSEWARE / WRITE ACCESS

【サクヤが本当に残したもの】
────────────────────────────────────────

残したのは、答えの文章ではない。

・最後の欄を空のまま保存できる設定
・観客の操作をSOURCEと別色で残す機能
・候補文へDERIVEDを強制表示する規則
・MODE 01〜09を一個の点数へ統合しない処理
・作品終了後も次の観客を受け入れるVISITOR番号

二人は、これらを別々の機能だと思って完成させた。
一周目のエンディング後、観客がソース表示を開くと、
すべて同じコミットで追加されていたと分かる。

コミット作成者：SAKUYA
コミット時刻：02:13:55
入力中の記録開始：02:14:02
入力中の記録終了：02:14:06.8

コミットメッセージ：

final field can stay empty

英語は流暢にしない。
サクヤが機能名へ合わせて短く書いただけの文にする。

【ヒント台帳】
────────────────────────────────────────

ヒントは、文章で謎を解説しない。
時刻、ラベル、色、ファイル名、操作結果へ埋める。


PROLOGUE｜大学前

表向き：三人が同じ大学の前に立ったことはない。

ヒント：大学前の掲示板に、コンテスト作品のQRコードがある。
一周目は読めない大きさ。
二周目のSOURCE表示では、現在開いているページと同じパスが見える。

意味：観客が見ているサイトは、物語内の提出作品でもある。


PROLOGUE｜Slack

表向き：三人の出会いと共同制作の始まり。

ヒント：サクヤが最初に作った共有フォルダは空。
所有者欄だけ「SAKUYA」、権限欄は「EDITORS: 3 / VISITORS: 0」。

二周目は「VISITORS: 1」に変わる。


青りんご

表向き：顔を知らない三人の待ち合わせ目印。

ヒント：作品内のカーソル位置を示す印も、青りんごと同じ緑。

観客の操作色だけが、三人の担当色に属さない。

意味：青りんごはサクヤの持ち物ではない。
これから来る人を見つけるための印。


GX / 00｜酸素

表向き：不要物が地球を変えた歴史。

ヒント：観客が置いた光へ「VISITOR TRACE」と表示される。
物語が始まった直後から、観客の操作は保存されている。


MODE 01｜地球の一呼吸

表向き：季節変動と長期上昇。

ヒント：年を戻してもVISITOR TRACEだけは元の位置へ戻らない。

意味：データの時刻と、観客が触れた時刻は別に流れている。


MODE 02｜青い循環系

表向き：海流と風の移動。

ヒント：14日計算の線はデータ終端で止まる。
カーソルだけはその先へ動かせる。

意味：分からない先を、線が勝手に埋めない。


MODE 03｜森の気候装置

表向き：森、雨、サクヤの最終ログ。

ヒント：4.8秒の記録IDが表示される。

input_trace_0214_048

末尾に本文フィールドがない。
記録されているのは時間だけ。


MODE 04｜共進化プロトコル

表向き：花と虫の記録された関係。

ヒント：線がない対象へ「NO RELATION」ではなく「NO RECORD」と出る。

意味：返事がないことから、理由までは決められない。


MODE 05｜すべては次の資源

表向き：再資源化、焼却、埋立、不明。

ヒント：「不明」の粒子を観客が別経路へ移すと、即座にSCENARIOへ変わる。

意味：空欄を埋めた瞬間、出自が変わる。


MODE 06｜人類世の傷跡

表向き：夜間光と排出量。

ヒント：二つの層を結合しようとすると「KEEP SOURCES SEPARATE」と出る。

意味：似た分布でも、同じデータにはならない。


MODE 07｜地球からのメッセージ

表向き：地震の到達差と4.8秒の選択。

ヒント：選択肢が出てから4.8秒間、何も押さない。
その場合だけ、入力欄の右下に鍵の印が一瞬出る。

鍵を押す必要はない。
見えた事実だけが解除条件へ保存される。


MODE 08｜三つの生態系

表向き：生態、社会、文化・記憶の三層。

ヒント：共有フォルダの同期表示を開くと、最終同期者が出る。

LAST STRUCTURE SYNC: SAKUYA
LAST CONTENT SYNC: AMANE

意味：サクヤが最後に触ったのは文章ではなく構造。


MODE 09｜人工物の共生化

表向き：潜在量、現在値、仮想ネットワーク。

ヒント：2050年をSOURCE色で表示すると警告が出る。
アマネがSCENARIOへ直したあと、変更履歴に古い一行が見える。

changed by SAKUYA:
future_is_observation = false


MODE 10｜未完の地球センスウェア

表向き：01〜09と観客の軌跡が重なる。

ヒント：UNIT MISMATCHの詳細を開く。
単位の一覧の最後に、数値ではない項目がある。

VISITOR / write permission pending

一周目はpending。
必要なヒントが揃うとgrantedへ変わる。


ENDING A

ヒント：NO DATA ADDEDが解除条件の一つ。
何も書かない選択も有効とする。


ENDING B

ヒント：白と青のファイルを両方開く。
青い候補文のメタデータにauthor欄はない。
generator欄だけがある。


ENDING C

ヒント：2050年宛ての文は、サクヤの入力欄へ入らない。
新しいスレッドとして作られる。


────────────────────────────────────────
【トゥルーエンド解除条件】
────────────────────────────────────────

必須条件は五つ。

1. A、B、Cのどれか一つを最後まで見る。

全エンディング周回は要求しない。

2. 二周目でVIEW SOURCEを一度開く。

3. MODE 07の選択画面で4.8秒待つ。

4. MODE 10のUNIT MISMATCH詳細を開く。

5. トップへ戻り、傷の増えた青りんごを押す。

不足している場合、青りんごは普通に少し揺れるだけ。
条件が揃っている場合、クリック音が鳴らず、画面の階層が一段外れる。

【トゥルーエンドで観客が理解すること】
────────────────────────────────────────

・サクヤの最後の言葉は見つからない。
・4.8秒は暗号ではない。
・候補文は最後まで候補文。
・サクヤが先に作っていたのは、観客を作者側へ入れる権限設定。
・空席は、誰かをサクヤの代用品にする席ではなかった。
・観客はサクヤの文を完成させない。
・自分の名前で、その次の行を始める。

────────────────────────────────────────

使ってよいミスリード

・青りんごは、顔を知らない相手を見つける印。
・椅子はVISITORへ書き込み権限を渡す場所。
