# 場面仕様｜production_year 背景境界

## 結論

`production_year`は一つの場所ではない。現在の展示ブース・端末前、三人それぞれの遠隔制作画面、海に近い町の共同作業室、駅・電車・中古機材店などを行き来する。scene全体へ`production-night-v2`を固定しない。

本文・step ID・日時は変更せず、背景だけを次の境界で切り替える。

## 最低限必要な切替点

1. scene開始前：`production_year_001`から展示ブース`exhibition-v3`。
2. 最初の回想：`_006`のtransition中に切替、`_007`から遠隔制作。
3. 十一秒の現在挿入：`_150`から展示ブース、`_156`から遠隔制作へ戻す。
4. 駅への移動：`_168`で駅背景へのフェード開始、`_169`で切替中、`_170`表示前に駅背景へ切替完了。
5. 初めて同じ机：`_175`から共同作業室`production-shared-meeting-v3`、`_195`表示前に終了。
6. 友人テスト：`_200`から共同作業室、`_215`表示前に終了。
7. scene終端の現在復帰：`_259`から展示ブース。

## 切替運用

- 背景切替は対象stepのactivation時に一度だけ実行する。同じstepの再描画でtransitionを再生しない。
- `_086`〜`_089`は短いモンタージュとして人物別背景を使う条件付き承認区間である。実画面で切替が騒がしく見える場合は、この4stepを中立の`online/remote`背景へまとめる。
- cueが欠けた場合は検査を失敗させる。無印の`room-v1`を代替背景として自動適用しない。

## 誤配置を防ぐ条件

- `_001`で`production-night-v2`を出さない。ここは現在の展示ブースである。
- `_007`〜`_079`、`_122`〜`_167`の遠隔制作を、三人が夜の同じ共用室にいる場面として描かない。
- `_060`〜`_079`をアマネ私室へ固定しない。アマネ私室は本文上の焦点が成立する`_080`から使う。
- `_122`〜`_129`をミズハ私室または園芸売り場へ固定しない。園芸売り場は学内チャットへ添付された写真内の場所である。
- `_150`〜`_155`と`_259`〜`_261`は過去の制作室ではなく、現在の展示ブースである。
- `_168`で駅へのフェードを始め、`_170`表示前に駅へ切り替える。共同作業室へは先行せず、本文で入室する`_175`から切り替える。
- `_195`の帰りの電車以後に、共同作業室背景を残さない。
- `_254`〜`_258`は夕方の予約・相談であり、`_257`に書かれた未来の集合予定に合わせてday背景や共同作業室へ切り替えない。実際の次回集合は次sceneの不在場面である。

`novel-bg-production-shared-meeting-v3.png`は20・30側から共有された採用素材名であり、この10担当worktreeでは背景mappingや素材ファイルを変更しない。
