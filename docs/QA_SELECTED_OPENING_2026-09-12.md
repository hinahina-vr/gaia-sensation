- `assets/opening-selected-20260912/`：原本PNG3枚・WebP6枚・選定記録・README。既存の候補9枚と旧画像は保持。

## 画像変換・読込容量

再生成・再描画・原本の切抜きなし。表示用WebPは非可逆圧縮で、原本PNGとの画素完全一致を意味しない。通常1672×941、軽量834×469。変換は `scripts/encode-selected-opening.mjs` で再現可能。

| 場面 | WebP品質 | 通常版 | 軽量版 |
| --- | ---: | ---: | ---: |
| 初対面 | 84 | 298,482 bytes | 109,264 bytes |
| みず | 92 | 265,316 bytes | 95,524 bytes |
| あめ | 92 | 376,704 bytes | 129,592 bytes |

最初の品質92変換では、既存の保守的な初期未圧縮1MB上限を超えた。初対面のみ品質84に調整し、最終版は **990,666 bytes / 1,000,000 bytes**。試験の画像参照抽出を固定旧ファイル名から実際のCSS変数へ変更し、新画像を集計から漏らしていない。
