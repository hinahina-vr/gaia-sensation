# コンセプト後半：世界を生成し、プレイで神話にする（2026-09-08）

## 対象と変更

`3a14ec587a8fb7203b37674c12d95a77c1cf4a78` を基点とするローカル作業ツリー、`concept-8`。対象URLは `http://127.0.0.1:4447/concept/`。製作者の提示文をもとに、03〜06を「AIが私を分析する仕組み」から「人間と機械が世界をつくり、プレイによって物語が生まれる仕組み」へ改稿した。

- 冒頭の「公開予定」「近日登場」を行ごと削除し、残るプロジェクト情報を2列に調整。03より前のHTMLは、この行の削除とCSS/JSのキャッシュ識別子を除いて基点と完全一致することを検査した。
- 03：神話製作機械を、世界の断片からプレイヤーが生きられる世界を用意する機構として定義。
- 04：公開データを `MYTH SEEDS` として捉え、海流から「境界」「循環」「見えない流れ」の3つの物語を読む例を追加。実装画面と創作上の比喩、科学的結論を区別。
- 05：`ARCHIVE`、`PANTHEON`、`POSSIBLE SELVES`、`WORLD MODEL`、`MYTH ENGINE`、`ORACLE`、`PLAY`、`PLAY LOG` の8役からなる構想図へ置換。中心は人格的な「神AI」ではなく、解釈をプレイ可能な世界へ編成する神話機関。
- 循環タブは `RECORD → INTERPRET → GENERATE → PLAY → CHOOSE → RECORD` の6段階。神託は本人への診断・正解ではなく、プレイヤーに返される問いとし、最後の意味付けと選択が本人に残る思想を維持。
- 06：シミュラークルを一時的に生成され、経験を記録へ返す世界として定義し、『惑星の放課後』を第01世界に位置づけた。放課後の観測室、古い端末、ノート、小さな神々という空気を文章で表現。
- 旧人物分析のイラストと旧構想図はページから参照を外した。画像ファイルや履歴は削除していない。新規画像生成はせず、構想図は折り返し・拡大・読み上げに対応するHTML/CSSの文字と構造で描いた。
- 現行の制作済みシナリオと、生成AIが世界を編成する設計構想を区別。閲覧者の記録収集、保存、外部AI送信をこのページに追加していない。

安田均『神話製作機械論』の著者・刊行年（1987年）は[国立国会図書館の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000001957936)で確認。本文には出典リンクを付け、この世界観は同書の引用・要約ではなく本作独自の構想である旨を明示した。書誌ページ以外の外部リソースは追加していない。
