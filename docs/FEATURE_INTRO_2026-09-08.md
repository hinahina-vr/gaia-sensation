# 地図・センサーの機能紹介とヘッダー修正（2026-09-08）

対象は `63ec6ffdb495256fde6ad1e58c7c963954c741c3` を基点とするローカル作業ツリー。先行する未公開変更を維持し、コミット・push・デプロイは行っていない。

## 変更内容

- 地図とセンサーの初回入場時に、3つの見どころを図と短いコピーで紹介するモーダルを追加。地図は「リアルタイム」「年ごとの変化」「統計・AI分析」、センサーは「みんなの観測」「自分の機器で参加」「記録の分析・AIへの質問」。既存機能と利用条件に合わせ、AIには本人のAPIキーが必要であること、地図の統計・AIは対応する時系列・比較展示が対象であることも明示した。
- 主ボタンでそのまま体験へ進める。操作ガイドは任意の別ボタンで開始。同じタブでは繰り返し自動表示せず、既存の地図／センサーガイドから見返せる。既読キーは地図v5・センサーv2。以前のガイドを見た利用者にも新しい紹介を表示する。
- 既存ガイドと同じモーダル管理を使い、紹介中は地図の自動展示を一時停止。公開センサー地図の紹介だけではログイン画面へ移動しない。センサーの操作ガイドを選んだ場合にのみ従来の参加案内へ進む。
- PCは横3枚、スマホは縦3枚。短い画面は本文内をスクロールし、閉じる／主ボタンは画面内に保持。キーボードフォーカス、Escape、動きを減らす設定にも対応。背景のみ80%の不透明度で、文字そのものは薄くしない。
- トップ画面に出てしまった黒い固定帯を解除。出典本文を上部ヘッダーの下までスクロールした間だけ不透明背景を使い、トップへ戻すと解除する。
- 地図タイトルの番号と、タイトル横／直下に重複していたライブバッジを削除。展示選択に使う内部番号・一覧番号は維持。タイトルの読み上げ名からも番号を除いた。
- 観測パネルの「ライブ」は赤背景・明るい文字に変更。取得中・保存値・参考値・遅延・接続停止の区別は維持する。

主な実装ファイルは `mode-entry-guide.js`、新規 `mode-feature-intro.css`、`app.js`、`sensors/sensor-platform.js`、`navigation-controls.css`、`data-journey.js`、`map-ui-grid-polish.css`、`realtime-exhibits.css`、`src/exploration/realtime-exhibit-status.js`。HTML・ローダー・関連する3展示モジュールのキャッシュ識別子も更新した。既存ブラウザー試験の既読データを新しいガイド版に更新し、新規紹介試験では旧版既読を使って移行を検証する。
