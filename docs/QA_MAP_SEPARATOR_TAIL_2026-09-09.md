# QA — 2026-09-09 地図セパレーターを0.5秒短縮・退場の余韻

## 依頼と対象

ユーザー原文：

> セパレーター表示0.5秒短く　あと　帯が消えるとき、少し余韻持たせて　演出の途中で切り変わってるようにみえる

地図展示共通の帯セパレーターを対象と解釈。全体を3.5秒から3.0秒へ短縮し、静止保持を調整して退場・背景復帰へ時間を配分した。ノベル本編／BEYONDの章区切り、地図入口の「世界を観測する」タイトル、台本・保存データは変更しない。先行の入口／統計UI修正も保持。

## 再現と修正

変更前の実時間採取では、背景の不透明度が約0.44まで下がった時点で、帯の移動は画面幅の約26％にとどまっていた。390px幅では、最後に表示されたフレームでも約74％で、帯が画面外へ出る前に終了。文字の読み時間だけでなく、帯の退場と背景のフェード、JSの終了処理の順序が原因だった。

`app.js` と `map-ui-grid-polish.css` の共通時間・段階を調整：

| 段階（開始からの予定時刻） | 変更前 | 変更後 |
| --- | ---: | ---: |
| 帯の登場完了 | 600ms | 600ms |
| 文字の発光ピーク | 735ms | 735ms |
| 文字・副題の表示完了 | 930ms | 930ms |
| 文字のフェード開始 | 3050ms | 2200ms |
| 帯の退場開始 | 3260ms | 2450ms |
| 文字の消失 | 3300ms | 2500ms |
| 帯の退場完了（102％移動） | 3500ms | 2850ms |
| 背景の暗さを戻す区間 | 3400–3500ms | 2850–3000ms |
| 演出全体 | 3500ms | 3000ms |

- 帯の退場を240msから400msにし、終盤に減速するカーブへ変更。文字は移動させず300msで消し、その最後の50msだけ帯の退場と重ねる。
- 帯が完全に抜けてから、背景と元の見出しを150msで戻す。
- `animationend` で後片付けするため、CSSの開始が描画フレーム分遅れても通常の固定タイマーで切らない。アニメーション停止時などの後片付けには、予定時間＋250msのフォールバックを残す。切り替え・閉じる操作では旧イベントとタイマーを解除。
- 基本地図の点・森林描画・POI判定も実際の終了まで待機。描画開始時刻を終了に合わせ、余韻の途中で点が出ないようにした。
- 動きを減らす設定は2460→1960ms。移動・発光なしを維持し、退出フェードは87.6→240ms。
- `gaia-mode-loader.js`／`index.html` の関連キャッシュ識別子を更新。
- 回帰試験を追加し、既存の時間検査を新仕様へ更新。森林試験は古い展示番号03を現在の08へ、案内既読キーと展示数の前提も現行へ更新した。
