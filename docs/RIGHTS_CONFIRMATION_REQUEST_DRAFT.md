`npm run build:release` は権利レビュー未解決のままでは終了コード1で停止します。これはローカルの公開用ビルド経路であり、Cloudflare Dashboardからの手動配信や既存Git連携の権限を制御するものではありません。

公開判断には担当者・日付・決定記録ファイルと、チェックが出力する現行素材範囲の `scopeSha256` を記録します。提供元の条件確認と、`owner-accepted` による製作者判断は区別します。データ・素材台帳・依存範囲が変わると古い判断は無効です。`excluded` の文字だけでは公開可能になりません。ファイル除外は実施・検証後の残存範囲に対する判断とし、`excludedPaths` に列挙したファイルと台帳項目の不在を検査します。
