# FAO 食料展示の出典と加工

依頼：食料需給表と食料安全保障指標を、別々の演出で追加する。展示70・71をローカル実装。公開・プッシュはこの依頼に含めていない。

## 収録範囲

| 展示 | 内容 | 期間 | 表現 |
|---|---|---|---|
| 70 食料を育て、分かち合う | 穀物、小麦、米、とうもろこし、大豆、じゃがいも、肉類、野菜、果実の9品目群。生産・輸入・輸出と重量ベースの品目別自給率 | 2010–2023年 | 芽の色・大きさと、輸入（水色）／輸出（橙）の粒 |
| 71 食卓を支えるつながり | 穀物輸入依存度（21035）、平均食事エネルギー供給充足率（21010） | 前者2000–2002〜2021–2023、後者2000–2002〜2023–2025 | 正負に応じて内外へ動く輪。充足率は別の目盛 |

品目群を合算した「全食料の自給率」や、日本のカロリーベース自給率ではない。二つの安全保障指標はFAO公表の3年平均を保持し、隣接期間の重複を明示する。

## 欠測と計算

自給率は `P / (P + M - X) × 100`。在庫変動を含むFAOの「国内供給量」とは区別する。数量は千t。欠測を0にせず、負の数量または分母0以下からは算出しない。原本にある負の輸出量2セルも改変せず保持。100%超の計算結果、負の公表輸入依存度は値を切り詰めない。色のみ凡例の端で飽和する。

今回のFBS原本には日本の記録がない（API、一括CSVの全行で照合）。日本を他資料・他国の値で補っていない。FSの日本は穀物輸入依存度の2000–2002〜2007–2009のみ収録され、今回の供給充足率にはない。画面には日本を残し、該当期間を「算出・数値なし」とする。この取得版の事実であり、日本の統計そのものが存在しないという意味ではない。

FAOの国・地域コード、年／期間、数量、フラグを保持。推計・補完区分は原資料のもの。国の位置はNatural Earth 50mの当該国自身のM49を使った代表位置で、親国のコードを流用しない。世界・地域集計を除外し、旧国家を現国家へ付け替えない。座標のない記録も選択一覧には保持する。粒・輪は模式演出であり、実際の農地・港・貿易相手国・航路・速度ではない。

## 再現

`node scripts/fetch-fao-food-sources.mjs --metadata --bulk` で原本を取得し、`python scripts/build-fao-food-data.py` で抽出する。`python scripts/verify-fao-food-sources.py` は独立した処理で全収録セル・単位・フラグを原本と照合する。`npm run check:food`、`npm run check:food:browser`、`npm run check:food:lifecycle` が計算と実ブラウザーの回帰試験。

統計分析は国・品目／指標ごとの時系列。自給率は「公表数量からの算出値」とし、FAO公表指標と混同しない。保存対象はブラウザー内の分析条件。新規のファイル書き出し・配布ZIPは作成していない。
