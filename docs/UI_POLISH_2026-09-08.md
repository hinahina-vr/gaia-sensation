# 展示・スマホ画面の表示調整（2026-09-08）

対象は `63ec6ffdb495256fde6ad1e58c7c963954c741c3` を基点としたローカル作業ツリー。先行する未公開変更は維持。コミット・push・デプロイは実施していない。

## 反映した依頼

- 公開プロフィール、説明ダイアログ、地図の地点カード・観測パネル等の背景を80%不透明に統一。親要素のopacityは落とさず、文字・アイコンを維持（`panel-surfaces.css`）。入れ子の観測パネルは背景の二重掛けを避けた。
- スマホの下部メニュー左右に `‹` / `›` を追加。全30展示を前後に送り、30→1、1→30も循環する（`map-mobile-shell.js` / `.css`）。
- CO2の現在年をスマホでも常時表示し、再生・スライダー・矢印キーと同期。「1960年」のように単位を付け、年表・年次統計・関連スケールも揃えた（`app.js`、`map-ui-grid-polish.js`、`estat-exhibits.js`）。
- 地点データが下部の観測パネルに隠れる問題を修正。実際のパネル高さを測って上下を分離し、短い画面はスクロール、横向きは左右配置にする。
- 最終画像で見つかった320pxの地点名と閉じるボタンの重なりも修正。閉じるボタンの幅を確保して地点名を折り返し、全文を残す。
- 対象の地図・統計パネルのPERIOD、EARTH NOW、LIVE等の案内を日本語化。観測機関・サービスの正式名称、単位、内部データの状態名は維持。将来の英語モードは今回追加していない。
- PC・スマホのリアルタイム見出し右に点灯する「ライブ」表示を追加。保存値・参考値・取得中・遅延・切断を区別し、保存データをライブ扱いしない（`realtime-exhibits.css`、`realtime-exhibit-status.js` と各展示モジュール）。
- タイトルへ戻るボタンの書体を画面共通の日本語書体へ揃えた（`navigation-controls.css`）。
- サウンド画面の不要な「SOUND ARCHIVE」を削除（`sound-mode.js`）。
- キャラクター設定資料のセクションを画面から削除。元の画像ファイルは保持（`index.html`）。
- スマホのキャラクター引用欄をPCと同じ明るい背景・濃い文字のデザインへ変更（`character-mode.css`）。
- センサー画面上部の戻る・ガイド・音声ボタンを上16px、高さ44pxで揃えた（`sensors/sensor-platform.css`）。
- スマホの出典ページで本文に重なっていた二重の固定データ表示を外し、本文の通常配置に変更。ヘッダー部分は黒の不透明背景で下の本文が透けない（`data-journey.css`、`opening.css`）。これは背景80%指定とは別に依頼された例外。
- オープニングの説明文を欠けずに1行へ収めた（`opening.css`）。
- 地球場面の縦線・横線の装飾を削除（`opening.css`）。
- 最後の選択メニュー全体に出る白いフォーカス枠を削除。個々の操作ボタンのキーボードフォーカス表示は維持（`opening.css`）。
