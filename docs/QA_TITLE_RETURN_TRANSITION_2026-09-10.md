# #topからタイトルへ戻るトランジション

## 依頼と再現

ユーザー原文: 「http://127.0.0.1:4492/#top　から　タイトルに戻るとき　1フレームで遷移して風情がないので、　ちゃんとトランジションつけて」。

変更前の`/#top`直入り→「タイトル」は、ハッシュを外したページへの`location.replace`で再起動。タイトル→データ探索→「タイトル」の同一ページ内の経路は、戻るクリック後の最初の描画フレーム（15.6ms）で入口を隠し、タイトルを表示していた。どちらも切替を包むトランジションがない状態を実操作で確認。`artifacts/title-return-transition-2026-09-10/before/report.json`に2経路の合格した再現検査と画面を保存。

## 実装

- 入口を残したまま560msで静かに暗転し、全面を覆った状態で100msの間を置き、タイトルを1000msでフェードイン。通常の演出長は約1.7秒（描画待ち・入力・撮影を含む通常の計測は約1.8–1.9秒）。拡大縮小・フラッシュは加えていない。
- `#top`などへ直接入った場合も、必要になった時点で既存タイトルのコントローラーを一度だけ初期化。同じページのまま戻り、起動画面・音設定・オープニング全文を再生し直さない。
- タイトルの背景とロゴをデコードし、完全に覆っている間に戻り先を描画。画像待ちがあれば不透明な状態を維持（待機は5秒で上限）。
- URL変更・入口を閉じる処理は全面を覆った時点で実施。遷移中は背景をinertにし、連打・Enter・Escape等による割込みを抑止。完了後はロックを解き、中立の入口グループへフォーカスを戻す。スマホの入口ガイドも遷移完了後に開始。
- 動きを抑える設定では70ms＋130msの短いフェード。既存のBGM切替、音量・消音設定は保持。

変更ファイル: `opening.js`（遅延初期化と遷移）、`opening.css`（全面カバー）、`app.js`（暗転中に入口を閉じる）。`index.html`・`gaia-mode-loader.js`のキャッシュキーを`title-return-dissolve-20260910`へ更新。新規試験`check-title-return-transition-browser.mjs`と実装に合わせた`check-title-return-bgm-browser.mjs`、`package.json`の`check:title-return:browser`を更新。
