# 曲一覧の区切り帯削除・高さ調整 — 2026-09-11

## 変更内容

- `sound-mode.js`: `.sound-track-chapters` の生成を削除。星座・曲名変形に必要な曲一覧コンテナの参照は維持。
- `sound-mode.css`: 区切り帯のスタイルを削除。921px 以上の一覧の上余白を 32px → 8px、一覧の行高を従来値から 24px 削減。下端位置、曲ごとの表示領域・クリック範囲は維持。元から帯が非表示だった 920px 以下の縦一覧は高さを変えず、12曲をスクロールして選べる状態を保った。
- `gaia-mode-loader.js` / `index.html`: 対象 CSS/JS と親ローダーのキャッシュキーを更新。
- `scripts/check-sound-compact-rail-browser.mjs` / `package.json`: 削除対象・高さ・操作領域・折り返し境界・全曲へのスクロール到達性の回帰テストを追加。
- `scripts/check-sound-browser.mjs`: 既存の日本語 UI に対して古い英語ラベルを要求していたアサーションを現行表示へ更新し、削除した帯の再出現も検査。

曲順・曲名・音源・音量・解放条件・保存形式は変更していない。

## 制約・残件

Chrome の PC/モバイル幅エミュレーションであり、物理スマホ・Safari・実機スピーカーの聴感評価ではない。曲一覧の寸法・再生試験は既聴状態 fixture で全曲を解放し、実際の解放・保持は別のロック試験で確認した。このモードには今回対象となるファイル書き出し操作はない。

今回の変更はローカルのみで未公開。本番確認は未実施。以前からの短い横向き画面におけるストーリー操作部の重なりは、この曲一覧とは別の配置であり未解消のまま保持する。

再実行: プレビュー起動後 `npm run check:sound-compact-rail:browser`。配信 URL は `GAIA_BASE_URL`、出力先は `GAIA_OUTPUT_DIR` で指定可能。
