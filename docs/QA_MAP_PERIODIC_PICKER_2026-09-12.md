# 展示一覧を測定対象中心のタイルへ

依頼原文: 「これ系、日本だったり世界なのはグルーピングからして自明なので、だったら測定されている分子だけバーンと出してほしい　周期表みたいなイメージ　44だったらSO2　番号も究極いらんよ　詰めてスクロールバーなくすとかできるならそれも一興　リアルタイムだけ LIVE みたいなアイコン（赤いアニメーションマーク）つけてほしい」

主担当の解釈: MAPの展示選択UIを対象に、重複する地域・時間種別・番号の表示を省き、化学式・測定指標を大きくする。分子ではない気温・人口等には短い対象名を使う。同じpHでも海・川・湖、気温の平均・最高・最低など、選択に必要な違いは小さく残す。

基点 `db63742c12f0ec9a7538ba7073d6029d384e5e7f` の同一ローカル候補上で実施。push・デプロイなし。

## 変更

- `map-exhibit-categories.js`: 全71展示の短い測定対象ラベルを共通化。44はSO₂、45はNO、46はNO₂、47はNOx、51はCH₄など。BOD・COD・PM2.5などは指標の略号であり、分子式に置き換えていない。
- 既存の世界16／日本55とテーマ分類は維持。地域・「時系列」「比較」「試算」をタイルから取り除き、定期更新に分類される11展示だけに赤いLIVEを付与。
- LIVEは「現在接続できている」の断定ではなく定期更新型の目印。保存値・モデル値を含む既存の分類を維持し、メニューの説明にも保存値が含まれることを明記。展示内の接続状態・観測時点・出典は変更しない。
- 内部の番号テキストは維持し、描画時だけ非表示にする。装飾用に追加した空のspanもtextContentを変えないため、既存の番号ルート、ホバー説明、前後移動、レンダラーの参照を保持。アクセシブルな展示名と地域・時間分類の説明も残す。
- `map-exhibit-categories.css`: PCでテーマを2〜3列に並べる周期表風の一覧に変更。赤い点は1.8秒周期で穏やかに明滅し、動きを減らす設定で停止。開いた一覧が既存の凡例・読取パネルに隠れない重なり順も調整。
- `map-mobile-shell.js` / `.css`: スマホの展示選択も同じ記号と補足を使う4列の小タイルに変更。横幅600px以上では6列。テーマの移動ボタン、スワイプ、選択状態、読み方・操作パネルは維持。
- `app.js`: ガイドの「01〜05」参照を「赤いLIVE」に変更。`gaia-mode-loader.js` と `index.html` の関連キャッシュキーを更新。
- `scripts/check-map-periodic-picker-browser.mjs` を追加。既存の `scripts/check-map-exhibit-profiles-browser.mjs` は番号テキスト保持・アクセシビリティの検査を残しつつ、表示契約を測定対象／LIVEへ更新。`package.json` にブラウザ試験・構文検査を登録。

- PC・4Kの全体、320／390pxのスマホ、横向き、スワイプ後の大気タイル、更新したガイドをスクリーンショットで目視確認。
