## 変更前→変更後と理由

| 変更前の代表例 | 変更後 | 理由 |
|---|---|---|
| `その場で見た記録：園芸売り場の温度計 36℃` / `補助表示：LOCAL SOURCE` | 「園芸売り場の温度計は三十六度。ミズハがバジルの鉢のそばで見た値」 | 管理ラベルではなく、誰がどこで見た一点の値かを物語文で伝える。 |
| `公開された元の記録` / `SOURCE` | 観測所名、観測時刻、提供元を開いて確かめられる値 | 「正解」の印ではなく、出どころへ戻れることを具体化する。 |
| `DERIVED` | 「展示のために変換した表示」「ミズハが生成し、候補から選んだ文章」 | 計算・変換・生成の行為と責任者を直接示す。 |
| `CURRENT` / `RECORD` | 「現在の展示ブース」「再生中：公開前夜」 | プレイヤーの身体がいる場所と、端末内で再生する過去を混同させない。 |
| `VISITOR TRACE` | 「このプレイで私が開いた場所／順番」 | 来場者の何が残るのかを具体化し、地球の観測値と混ぜない。 |
| `SOURCE RECORD` | 「本人から届いた記録だけを表示」 | 最終画面で何が起こるかをそのまま選択肢にする。 |
| `DISCLOSE DERIVATION` | 「本人の記録と生成した部分を分けて表示」 | 作者と分類を分けて並べる選択であることを明示する。 |
| `PUBLIC BUILD CHANGED：NO` | 学園祭公開版1.0が書き換えられていない、という自然文 | 内部状態名ではなく、変わらない対象を具体化する。 |
| `localStorage`、保存件数、外部送信、次来場者への技術説明 | 本編から削除 | 展示テーマと人物の判断に不要な実装説明で物語を止めない。 |

## 残した正式な事実

- 園芸売り場の一点の値と広域の観測所の値は、測定条件を分ける。
- 研究・観測の提供元、対象時刻、方法へ戻れる入口を残す。
- 制作者が時間軸、色、動きへ変換した箇所は、元記録そのものではないと示す。
- サクヤ本人の原文と、ミズハが生成・選定した文は別カードにする。
- 生成した人、候補から選んだ人、サクヤ本人未確認を残す。
- 三人が確認した学園祭公開版1.0と、その後に二人が行った会場用変更を混ぜない。

## 回帰条件

- 可視本文に `SOURCE`, `DERIVED`, `CURRENT`, `LOCAL SOURCE`, `VISITOR TRACE`, `SOURCE RECORD`, `DISCLOSE DERIVATION`, `RESPONSIBLE`, `REFLECTION FIELD`, `CLEAR`, `localStorage`を残さない。
- 内部選択値 `SOURCE_RECORD` / `DISCLOSE_DERIVATION` と `recordType` は変更しない。
- `サクヤの分だけ、縁が乾いたまま`を維持する。
- `ARCHIVES｜任意閲覧`以降は変更しない。
