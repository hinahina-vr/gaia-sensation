# 展示矢印の効果音重複 — 2026-09-09

## 症状・原因・修正

添付画面の MAP 28「日差しを受け取る土地」の右矢印から MAP 29 へ移る操作を、ローカル Chrome で再現した。実クリックに加え、展示選択ボタンへ転送する `.click()` も共通効果音処理へ伝播し、決定音が2回鳴っていた。

`ui-sound.js` は実ユーザー入力のクリックだけを発音対象とし、内部のプログラム的クリックでは鳴らさない。クリックを capture で受けるため、イベント伝播を止める通常地図の矢印でも実操作の音を失わない。時間制限による間引きは行わず、別々の連続クリックはそれぞれ鳴る。

展示切り替えで別ボタンが静止カーソルの下へ来たときの余分なホバー音も修正。ホバー音は実際のポインター移動に結び付け、クリック由来のフォーカス移動とタッチには追加のホバー音を出さない。通常のマウスホバー音、戻る音、ネイティブ Enter／Space 操作、ミュートは維持。

変更ファイル: `ui-sound.js`、読み込み版を更新した `index.html`（`single-activation-20260909`）、回帰テスト `scripts/check-map-step-sound-browser.mjs`、npm コマンド追加の `package.json`。他の依頼による作業中変更は維持。

## 実ブラウザ検証

Windows Chrome、ローカル `http://127.0.0.1:4447`、1920×1080 と390×844。マウスクリック、タッチ、Enter／Spaceをブラウザ入力として実行。AudioContextをモックに置換せず、実際の Web Audio Oscillator の開始と、UI音声出力へ接続した AnalyserNode の非無音サンプルを記録した。BGMはミックスゲイン0で分離した。

決定音1回は既存の2つの音色パートで構成される。変更前は4ノード＝決定音2回、変更後は2ノード＝決定音1回。音色自体を削って数を合わせたものではない。

- `node scripts/check-map-step-sound-browser.mjs --before`: HEAD の旧 `ui-sound.js` を配信し、MAP 28右矢印1クリックで決定音2回を再現。
- `npm run check:map-step-sound:browser`: 19件合格。報告された矢印、逆方向、Enter／Space、MAP 01・05・06・15の矢印、スマホ見出し・下部ツールバー、連続2クリック、通常ホバー、プログラム的選択の無音、ミュート、戻る音。
- 各矢印で展示番号が1つだけ進むこと、決定音1回・追加ホバー音0回・実音声出力が非無音であることを確認。
- `node --check ui-sound.js`、`node --check scripts/check-map-step-sound-browser.mjs`、`git diff --check`: 合格。

回帰テスト整備中に、別展示へ移った直後の余分なホバー音と、伝播を止める矢印の経路も確認して修正対象に含めた。連続操作試験は、文字幅で位置が動く見出し矢印への固定座標ダブルクリックではなく、位置が固定された矢印に対する2回の実クリックで検証している。
