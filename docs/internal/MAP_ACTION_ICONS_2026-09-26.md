# 地図アクションのアイコン欠落修正

## 依頼・原因・修正

- ユーザー原文：「アイコン消えてんだけど」。添付は01「風がつなぐ世界」の下部、「データの出典」「統計分析」ボタンのアイコン欠落。
- 元のSVGを作る `map-ui-grid-polish.js` より早く、展示側が `gaia:map-adapter-ready` でボタンを生成する経路がある。`decorateMapActions` はその時点でSVGを複製できないと、空のアイコン枠を残していた。
- 複製できなかったアイコンだけを待機させ、地図パネル内に元のSVGが追加されたら同じSVGを複製する。全件の反映後はMutationObserverを解除する。即時に複製できる通常経路は待機しない。
- グラデーションIDの一意化、既存のSVG図形・CSS・ボタンの配置と大きさ、出典と分析の操作は維持。
- 6種類の展示モジュール→探索入口→遅延ローダー→HTMLの参照URLを更新。旧キャッシュのモジュールに修正前の処理が残らないようにした。

## 検証

対象：`3b8a0f12b8844094101dd8d578c30ef40778b01b` ＋ 未コミット変更。

- 再現：元のSVGを作るスクリプトのHTTP応答を1.8秒遅らせると、修正前は両ボタンのSVGが存在せず、空の枠になった。取得内容は差し替えていない。
- 修正後：タイトルから入る経路（1440px）、直接`#world`（3840px）、同じ1.8秒遅延条件（1440px）で復元。各条件で01・04・06・15・21・31・70・01の順に切り替え、計24回の表示検査に合格。
- SVGの存在・描画サイズ・図形・stroke・グラデーション参照先・ID一意性を検査。遅延条件の修正前後画像も目視で確認。
- 3種類の初回入場条件すべてで、修正前後のボタン位置・寸法が一致。
- 出典パネルの開閉、01の統計分析が利用不可であることを維持。
- スマホ幅390pxで01／06に直接入り、操作シートの両アイコン、出典の開閉、01の分析不可、06の分析画面で実際のチャート表示と閉じる操作を確認。
- `npm run check:mode-loader`（38検査を含む）、`npm run check:security-policy`、JS構文、`git diff --check`に合格。

Chromeはインストール済みブラウザを使用し、PC／スマホは表示幅・タッチのエミュレーション。実機スマホや本番の確認ではない。外部APIは遮断し、保存値・フォールバックを使用。CSPはローカルに本番ポリシーを適用したもの。

回帰試験：`npm run check:map-action-icons:browser`（スマホだけは `node scripts/check-map-action-icons-browser.mjs --mobile-only`）。証跡：`artifacts/map-action-icons-2026-09-26/{before,after,mobile}/report.json`、各PNG。レポートに元の完全SHAと主要ファイルのSHA-256を記録。
