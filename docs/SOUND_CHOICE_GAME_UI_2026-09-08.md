## 変更

- `opening.css`: ミント×金、青紫×シルバーの2色、二重の縁、下端の厚み、宝石風アイコン、小さな星の装飾。タイトルの太さと光彩も調整。
- `index.html`: 読み上げ対象外の星の装飾を追加。CSS/JSの読み込み識別子を `gaia-route-hover-help-1-sound-jewel-1` に更新。
- `opening.js`: マウスが入るたび／キーボードフォーカスで640msの一回限りの光を再生。フォーカスが残ったままの再ホバーでも再生し直す。
- 確定時は既存のdisabled・aria-pressed状態を使って沈み込みと短い発光を表示。既存のクリック内の音声開始、二段階rAF＋120msの画面切替は変更しない。
- 無操作時の選択点滅は追加しない。reduced motionでは新しい発光・拡大・移動を停止し、枠と明るさで状態を示す。
- 音声の初期値、音量10%、言語・説明文、タブ移動、設定の保存先、次画面のルートカードは変更していない。
