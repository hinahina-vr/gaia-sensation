# 星座から文字への連続アニメーション（2026-09-13、ローカル）

## 依頼と変更

ユーザー原文：「星座フォーカスすると文字になるけど、今連続性ないので、星座が文字の点になり、それをなぞるような美しい動きにして添付の間を補完するアニメーションってことね」

小さな星座を消して文字の位置へ新しい点を出す切替から、実際に見えていたSVGの星の位置を引き継ぐ動きへ変更。全12曲共通のフォーカス／ホバー処理を対象とする。

1. SVGの現在の位置・揺れを取得し、元の星と枝をCanvasへ受け渡す。
2. 約1.25秒かけて星が曲線を描いて広がり、文字の点へ移動。補助の点も元の星から分かれる。元の枝は星について伸び、薄れていく。
3. 文字の点として約0.16秒落ち着いてから、光の先端が既存の筆順を約1.9秒でなぞる。総時間約3.31秒。

元の日本語・英字の手描きパスと、日英中の字体を維持する。手描きパスのない翻訳文字は実フォントから点を採取し、着地後は従来のフォント描画マスクで文字を出す（中国語の正確な筆順データを新規実装したという意味ではない）。スマホは既存の一覧UIを維持。reduced-motionでは移動を省いて直ちに最終表示する。
