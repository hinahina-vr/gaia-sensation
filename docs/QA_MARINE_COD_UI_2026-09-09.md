# MAP 31 — 操作欄・COD説明・色凡例・地点拡大

## 対象と変更

2026-09-09の依頼「他の展示とUIを合わせる／COD・BODの説明／密集POIを選べる拡大／汚れの程度を色と凡例で示す」へのローカル修正。

- PCは共通の下部操作欄へ統合。展示番号・カテゴリ・左右矢印・一覧の入口・出典／分析ボタンの配置を共通化。幅1200px以下のPCでは2段にして文字と操作を重ねない。
- 色凡例は初期表示から常時表示。年度平均CODを青→緑→黄→橙→赤で示す。0、1、2、3、5、9 mg/Lの固定の数値位置で補間し、9以上は同色。色と点の描画は同じ定義を使用する。欠測は灰色の輪。選択地点の数値も同じ色。
- CODは有機物による汚れ（有機汚濁）の目安であること、BOD・DOとの違い、COD75と年度平均の違いを説明。毒性・遊泳可否・環境基準の達成をこの配色で判定しないことを明記。自然由来の有機物でもCODは高くなり得る。
- MAP 31だけ拡大上限を8倍から512倍へ変更。ホイール、拡大／縮小ボタン、キーボードの共通拡大経路、ピンチ、地点への移動が同じ上限を使う。他展示は8倍を維持。
- 地点一覧で選択すると最低64倍へ移動し、既にそれ以上に拡大している場合は倍率を維持。周囲の地点を一覧の先頭グループに出し、名前・実測値・地点コードを併記。同一座標も別々に選べる。座標をずらしたり、未観測海域へ補間したりしない。
- スマホは共通の読み方／操作シートを使用。年度操作を1行にまとめ、縦／横向きで凡例を配置。全国表示は見出し、凡例、実際の操作欄の位置を考慮して合わせる。読み方の5年度の値も維持。

環境省の2020〜2024年度JSONそのものは変更していない。保存値であり、リアルタイム水質ではない。

説明の確認先: [環境省・COD/BOD等の用語説明（付属36頁）](https://www.env.go.jp/content/900542733.pdf#page=38)、[環境省・75%水質値の評価方法](https://www.env.go.jp/hourei/05/000057.html)。元データへのリンクも画面に維持。

## 再現と回帰テスト

環境: Windowsの実Chrome、`http://127.0.0.1:4447`。実データを描画し、マウス・タッチ・2指ピンチをブラウザ入力として実行。スマホは端末エミュレーションであり実機試験ではない。

- 変更前のCOD JS/CSSと8倍制限をブラウザへ配信して再現。1440×900で幅320px・高さ527pxの独自カード、初期状態では見えない凡例、8倍で無効になる拡大ボタンを確認。390×844でも凡例非表示と8倍制限を再現。証拠: `artifacts/marine-cod-ui-2026-09-09/before/`。
- 最終UI: 3771×2100、2560×1440、1920×1080、1440×900、1280×800、1024×768、901×600、768×1024、390×844、320×568、844×390の11画面で合格。操作の実ヒット、画面内への収まり、文字と値、凡例、横スクロールなしを検査。全サイズの全国表示で2,042地点すべての中心がパネルに覆われないことを座標投影と `elementFromPoint` で確認。
- 東京湾の実地点 `1360101` と `1360152` を512倍で分離し、それぞれをクリック／タップして正しいIDと値を選択。拡大上限、選択時の倍率維持、縮小、ホイール、ドラッグ後の選択、実ブラウザの2指ピンチ、同座標地点の一覧選択を確認。
- 各色の数値位置、上限超過、欠測を検査。3.6 mg/L地点の実Canvasピクセル `[249,197,96,217]` と数値の色、凡例の色が期待値と一致することを確認。
- 展示一覧を実際に開閉し、下部矢印で31→30、31→01へ移動。他展示へ切り替えた後は上限8倍・CODの非表示を確認。
- 通し機能: 1440×900、390×844、320×568、844×390で5年度の元データとの一致、欠測、`<0.5` の表記、地図タップ、出典パネル、統計分析の実5点描画、年度自動送りと停止、Canvas波紋の実ピクセル変化、HTTP 503時のエラー表示と別展示への退出が合格。読み方パネルの5年分の値の可視性も確認。追加の1024×768でも同じ通し試験が合格。
- 関連する既存UI: 1920×1080、1024×768、390×844の天候系下部UIの位置・文字・操作・隣接UIを確認。こちらは既存テストの合成キャッシュを用いるレイアウト試験で、ライブデータの取得検証ではない。
- `npm run check:marine-cod`、変更したJSの `node --check`、対象差分の `git diff --check`: 合格。

試験中、凡例の「9以上」の折り返し、小画面の見出しとの重なり、移動した年別表示の非表示、1024pxで一部地点が凡例に隠れる問題も検出し修正。通し機能試験の後に全国表示のカメラ位置だけを最後に微調整し、最終ツリーで11サイズの全地点露出・UI・密集POI操作を再試験した。
