# 展示メニュー：奥行き発光とフォーカス表示（ローカル、2026-09-13）

## 依頼との照合

- 原文：「メニュー押した時、各ボタンもニュっとしてしゅぱぱぱってカッコよく表示してほしい」「世界から日本に切り替えた時も…同じ感じ」
- 修正指示：「いやもっとビカビカひかってZ方向にパラパラ出る感じよ 1.2秒ぐらいかかってもいい」
- 追加指示：「展示メニューはボタン押すんじゃなくてフォーカスで表示していいかな」

最初の約0.66秒のY移動・拡縮から、実際のperspectiveとZ移動へ変更。各ボタンが Z=-320px から手前の +48px へ出て収まる。白〜シアンの明るい縁・内側の光・外側の光が、ボタンごとに一度走る。1枚660ms、表示順の遅延は最大540ms、全体1200ms。世界16展示・日本55展示とも同じ総時間。メニュー再表示と両方向の世界／日本切替で再生する。

PCでは展示メニューへのホバー／キーボードフォーカスで表示。クリックは開いた状態を保ち、フォーカス後のクリックで閉じてしまわない。フォーカスを勝手に移さず、上下矢印キーで展示エリアのタブへ移動できる。Esc・外側クリック・展示選択で閉じる。Escや選択後にボタンへフォーカスを戻しても開き直さない。自動巡回・クルージングはメニューへ入った時に止める。スマホはタップと既存のモーダルシートを維持する。

reduced-motionでは移動・発光を省略し、すぐ通常表示。途中で設定変更・メニューを閉じる・タブを再切替した場合、古いアニメーションをキャンセルする。番号・展示の実ボタン・ルーティング・翻訳文・画像は変更しない。
