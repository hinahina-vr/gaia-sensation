# モード選択ボタンの文字はみ出し

- 対象: 0aa94d5後のローカル作業ツリー。ボタン内の文字のみを対象とし、ヘッダー位置は変更しない。
- 再現: Chromeの390px幅で実際に冒頭の音声OFF→スキップ→データを探索するを操作。4カードすべてでタイトルまたは説明の領域外描画を検出。原因はnowrapと狭いタイトル列。
- 最終依頼: 「折り返すんじゃなくて文字小さくして」。折り返し修正とスマホの行追加は取り消した。元のアイコン配置・カード構造を維持し、カードの実幅を基準にタイトルと説明の文字を縮小して1行に収める。共有CSSのキャッシュキーも更新。
- 1000px以下は2列にして、中間幅で4列のカードが極端に狭くなり文字が過小になるのを防ぐ。
- 回帰試験: `node scripts/check-intro-card-text.mjs`。360 / 390 / 412 / 768 / 1440px幅で、全カードのテキスト矩形とスクロール幅が枠内で、nowrapが維持されていることを検証。390pxの実画面も目視確認。
- 証跡: `artifacts/intro-card-text/before-390.png`、`after-390.png`ほか各幅。
- Android実機・本番配信は未確認。コミット・プッシュ・デプロイは未実施。
