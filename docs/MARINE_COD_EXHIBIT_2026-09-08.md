# 展示31「沿岸に残る、水の記録」— ローカル実装

依頼: 日本海域のCODデータがあれば新しい演出として追加。対象は日本海側に限定せず、日本沿岸の公開測定地点とした。01〜30の番号とデータは維持し、31を「水と森 / 日本 / 時系列」に追加した。

公開・push・commitは行っていない。検証対象はベース `fc510bf5a84517788e8227e3757634cab5f9e171` に本変更と先行する入口立ち絵・FIRMS背景修正を重ねたローカル作業ツリー。先行変更は維持した。

## 実装とデータ

- 環境省の公共用水域水質測定データ、海域・生活環境項目・年間値、2020〜2024年度。計10,186地点年度記録。最新年度は2,042地点（COD平均値あり2,041、欠測1）。出典、利用条件、原ZIP、ハッシュ、データ加工規則は `data/sources/japan-marine-cod/` に保存。
- 年度平均CODを実際の地点座標に表示。固定0〜9 mg/Lの色尺度・値に応じた半径。灰色の輪は欠測。波紋は測定地点を示す装飾で、流れ・拡散・汚染範囲を推定しない。DOや酸欠と区別する。
- 年度スライダー、自動年度送り、都道府県・地点の選択、地図タッチ、日本沿岸全体に戻す操作。地点のない年度は「記録なし」を表示。元資料のCOD75の定量限界注記も保持。
- 選択地点の年度値を統計画面へ渡す。短いCOD系列は実測点を表示し、記録数をCOD値として描かない。自動の傾向線・予測を追加しない。全年度欠測の地点では分析ボタンを無効化。
- 展示一覧、デモ巡回、31の次→01／30の次→31、見出し、副題、元データパネル、スマホの読み方・操作パネルに統合。
- 24fps上限・最大160万ピクセル。別展示・非表示・地図閉鎖中は描画停止。動きを減らす設定では波紋を静止。

主な追加: `src/exploration/marine-cod-{catalog,exhibit}.js`、`marine-cod-exhibit.css`、`data/japan-marine-cod.json`、取得／ビルド／照合／ブラウザ試験スクリプト。統合変更は `app.js`、`app-content.js`、loader、カテゴリ、mobile shell、各既存providerの解除処理、統計discoveryと対応するテスト。

- `python scripts/build-japan-marine-cod.py --check`: 全ZIPハッシュと生成JSONの再現性。
- `npm run check:marine-cod`: 新規モジュール構文、COD統計の5点・3点・1点の値と軸・単位、傾向線がないこと。
- `npm run check`: precheck、本体、postcheckを含め合格。数理、既存データ契約、loader、runtime分割、セキュリティ・権利台帳の既存チェックを含む。権利チェックの既存スコープとは別に、今回の環境省データ条件は上記READMEへ記録。

### 最終ブラウザ試験

`artifacts/marine-cod/qa/report.json`: **passed / page error 0**。1440×900、390×844、320×568、844×390で、実測値・COD75・年度キー入力・地図タッチ・出典・統計5点・欠測・定量限界・全providerへの切替・操作の到達性・80%背景・画面内収まりを確認。通常モーションの実ピクセル変化、自動年度送り2024→2020と停止、故意のHTTP 503時の案内と既存展示への退出も合格。

その後、CODグラフの横軸を小数付きの年ではなく2020〜2024の年度表示に調整した。影響範囲を `scripts/check-marine-cod-analysis-browser.mjs` で再試験し、1440・390・320幅の実際のCanvas描画呼出しが5年度を描くこと、5実測点、キーボードで2020年度3.5 mg/L／2024年度3.6 mg/Lの実際のツールチップを確認。最終SHA-256と画像は `artifacts/marine-cod/analysis-final/` に保存。統計の構文・数理・既存discovery試験も再実行した。

上記のPC／スマホ／小画面／横画面と統計グラフのスクリーンショットを目視確認した。展示切替直後のタイトル演出が終わった状態で配置を評価している。

## 利用と未確認の範囲

ローカルURL: `http://127.0.0.1:4447/?exhibit=31#world`。通常導線は地図→展示一覧→水と森→31。地域と測定地点を選び、年度スライダーを操作する。スマホでは「操作」から出典／統計分析、「読み方・凡例」から尺度と注意点を開く。

この展示の追加データは版管理対象のローカルJSONで、表示時に環境省へ再取得しない。統計画面は従来どおり画面内表示のみ。保存・ダウンロードのUIを新設しておらず、CSV/JSON/PNGの書き出しや外部アプリへの導入は対象外。原ZIPの保存と再生成・再照合は実施したが、配布用ZIPを新規展開した検証ではない。

ChromeでのPC・タッチ／スマホ幅エミュレーションであり、実機iOS/AndroidやSafari、本番配信、Cloudflareデプロイ、外部AI送信は未検証・未実行。CODは実取得済み原資料を使用し、その他のライブサービスの通信は試験中ブロックした。故意のHTTP 503試験をライブ障害の観測結果とは扱わない。
