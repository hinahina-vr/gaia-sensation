# GA4導入（ローカル実装）

- 測定ID: `G-GY90YZSS4D`。旧ID `G-4SPFE1574L` は使用しない。
- 対象: トップ、地図、キャラクター、音楽、物語のハッシュ経路と `/concept/`。センサーアカウント画面にはタグを導入しない。
- 有効ホストはHTTPSの `gaia-senseware.pages.dev` のみ。localhost、file://、ブランチプレビューではタグ・同意UIを作らない。独自ドメイン移行時は許可ホストを明示的に更新する。
- 最新依頼「日本以外は同意」「最初に英語でポップアップ」に対応。Cloudflareの同一オリジン `/cdn-cgi/trace` の国コードだけを利用する。本文やIPを保存・GA送信しない。JP判定が完了した場合だけ拒否設定なしで計測。海外・不明・失敗・4秒タイムアウトでは明示的な同意までGoogleタグを読み込まない。
- 海外の初回同意ポップアップは常に英語。Accept / Reject は同じ大きさで、拒否・Escapeでも作品を利用できる。海外だけに小さな Analytics settings ボタンを表示し、再許可・撤回が可能。日本では両方とも非表示。選択は専用v2キーに日時とともに180日保存し、期限切れは再確認する。旧版の自動計測を同意と見なさない。
- 以前の拒否設定とGPC/DNTを尊重し、停止時はGAを無効化し `_ga` Cookieを削除する。広告・Googleシグナルは無効。
- ローカル実装のみ。IP由来の地域推定はVPN等で実際の所在地と異なる可能性があり、全地域の法令適合を保証しない。Google公式のBasic consent modeを参考に、未同意時はライブラリそのものを遮断する。
- 画面は許可リストから仮想パスを作る（例 `/exhibit/world-01`）。URLの検索パラメータ・任意のhash・外部参照元・ユーザー入力・座標はイベントに付けない。
- `page_view` はアプリが送信、同一画面は重複抑止。`navigation_mode` は `manual` / `cruise`。入口の `story_start` / `exploration_start`、統計ボタンの `analysis_open` も送る。
- 物語の章別進捗・読了率、全モバイル代理ボタンのイベント網羅は今回未実装。

## 公開前にGA4管理画面で必要な設定

1. 管理 → データストリーム → 今回のウェブストリーム。
2. **拡張計測機能をオフ**。自動履歴ページビュー、検索語・フォーム・外部リンクなどの自動収集を止める。コードの `send_page_view:false` だけでは拡張計測の履歴イベントを抑止できない。
3. 任意: カスタムディメンション `navigation_mode`（イベントスコープ）を登録すると自動巡回と手動閲覧を分けて分析できる。
4. 対象地域の同意要件に対応し、公開が許可され反映した後、画面を切り替え、GA4リアルタイム/DebugViewでID・重複・受信を確認する。今回公開操作は行っていない。
