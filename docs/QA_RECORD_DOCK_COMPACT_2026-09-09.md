# 記録展示の下部UI：2段化・高さ圧縮

## 依頼と対象

依頼原文：「これ　2行にできない　んで、UIの高さを圧縮したい　いま余白多いのでもったいないため」。添付は67の「届出移動量（下水道＋廃棄物）／0 kg/年度／2届出物質（kg単位）／燃料小売業／内訳ボタン」と、66の長い展示名。

解釈：添付の下部UIを、内容や操作を失わず2段に整理する。共通の記録展示65–69に限定して適用し、その他の年次展示・食料展示は元のレイアウトを保持する。公開は依頼されていない。

- 長い展示名の1行固定と列の内容幅への拡大を解除。全文を最大2行で読める列幅にした。
- 数値欄は1段目「項目名＋値」、2段目「補足＋内訳ボタン」。数量、単位、届出物質数、業種を変更していない。
- 上下パディング、見出しの固定高さ、単年度展示の期間欄の余白を削減。
- PC幅1440／3840：138px → 108px（約22%削減）。狭いPC幅1024のPRTR：214px → 135px（約37%削減）。
- モバイルは既存の2列構成と44pxの内訳ボタンを保持。

実装は `marine-cod-exhibit.css`。読み込み更新は `gaia-mode-loader.js`、`index.html` の `record-dock-compact-20260909` 識別子。回帰スクリプトと `check:record-dock:browser` コマンドを追加した。

## 再現と修正確認

添付と同じ条件を原データから選択：`E2301000-00118-00`、北海道網走市の配送センター、燃料小売業、2届出物質、移動量0。66／67を同じ地点で表示した。

変更前は1440／3840／1024の6ケースを撮影・計測。長い展示名が1行、値・補足・内訳が別々の段、138px／214pxの高さを記録。変更後は同じ条件を含む6画面サイズの12ケースで、2段の位置関係、長い題名の2行、全文と操作部の収まり、実クリックを検証した。

出典を開いた際に凡例が本文と原資料リンクに重なる既存症状も、今回の操作経路で再現した。記録展示では出典・分析を開いた間に背後の読取UIと凡例を非表示にし、閉じると戻す。再現画像 `after/1440-66-source-overlap.png` と修正後 `after/1440-66-source.png` を保持。原資料リンクの実ヒットと閉じた後の操作復帰を確認した。
