# 公開素材の整理

- 決定日: 2026-09-07
- 決定者: GAIA SENSEWARE 製作者（プロジェクト所有者）

## 未使用画像

製作者の指示により `assets/data/jaxa-fnf-riau.png` を削除する。削除前の追跡済みコード検索では、実行コードからの参照はなく、素材台帳と監査文書でのみ参照されていた。公開素材台帳からも除き、残存する素材範囲を公開判断の対象とする。ファイルはGit履歴から復元可能で、過去の履歴や既存の本番配信には変更を加えない。

## 生成画像・音楽

製作者の指示に基づき、制作元と出典・加工内容の記録に整理する。生成イラストは **OpenAI Imagegen**、生成音楽は **Suno AI** と表記する。既存の制作記録を参照し、科学データ画像やローカル合成音など別の制作元は区別して保持する。

現行素材の利用を継続し、本項目の公開保留を解除する。対象素材のSHA-256は `docs/rights-review.json` に記録する。
