解釈: 06〜20の下部ドックの書体・文字サイズ・スライダーを21に合わせる。15〜20では、日時と実際の表示値・地図が連動するスライダーを追加する。追加依頼では数値の字間を詰め、単位の可読性は保つ。

基点 `db63742c12f0ec9a7538ba7073d6029d384e5e7f` 上の同一ローカル候補。コミット・push・デプロイなし。他の未公開変更は保持。

## 実装

- `map-unified-dock.css`: 21と同じ明朝系の `--font-ja`、400ウェイト、タイトル・番号・主要数値のサイズに統一。06〜14の太い独自スライダーを21と同じネイティブrangeに合わせ、時点表示と目盛りを整理。スマホ縦横の配置も調整。
- 数値だけ `letter-spacing: -.06em`。単位は字間0と小さな左余白。値・小数点・符号・単位の内容は変更しない。
- `app.js`: 06〜14の既存表示値を主要数値・単位・補足に分ける。地震件数・降水量・人口などは既存の選択値を参照する。12の説明型表示は数値表示に捏造しない。
- `src/exploration/live-exhibits.js`: 15〜20にJSTの時間スライダーと目盛りを追加。最古から1時間刻みで選択でき、右端で最新に戻る。手動操作中は地点自動送りを止め、別系統の展示へ出ると時間選択を解除。
- `src/exploration/live-timeline.js` / `live-data.js`: 選択日時の47地点データを表示へ引き渡し、数値・地図・風場・出典の時刻をそろえる。閲覧中の履歴窓は定期更新でずれないよう固定し、最新へ戻ると更新済みデータへ合流。欠測を別時刻や別都市で埋めず、0は保持する。東京の古い緊急保存値より全国側の値が新しければ、その新しい値と出典を使う。
- `sensor-platform/src/prefecture-field.ts`: 既存Open-Meteo/CAMSの全国取得へhourlyを加え、現在以前の最大24時間を返す。気象と大気の独立キャッシュ、更新失敗時の前回値を維持。Cloudflare / Workersスキルに従って取得の時間制限・応答サイズ上限・位置数検証を維持／追加し、生成した `_worker.js` も照合。
- `data/live-prefecture-fallback-v1.json`: 同じ取得処理で実配信元から取得した47地点・6指標・24時間の保存モデル値を同梱。時間別データがない場合はスライダーを無効にして理由を表示。
- `gaia-mode-loader.js` / `index.html` / `src/exploration/index.js`: CSS追加と関連モジュールの読込キーを更新。新しい回帰試験を追加し、主要な試験コマンドを `package.json` へ登録。
