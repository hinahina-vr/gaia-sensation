# 青猫のキャラクター紹介

2026-09-07 / ローカル実装。push・デプロイは行っていません。

- キャラクター設定に4人目の「青猫」を追加。本名・読み仮名の設定は持たず、表示名だけを掲載します。
- `assets/characters/aoneko-silhouette.svg` は、この変更でコードとして制作したオリジナルのベクター図形です。外部画像・写真・生成画像は使っていません。顔立ちや性別を固定せず、青系の中性的な人影として描いています。
- 既存の物語にある、展示ブースでの出会い、サークルへの参加、ESP32の試作・データ連携をもとに紹介文を追加しました。引用風の一言はキャラクター紹介用の新規コピーです。物語本文は変更していません。
- 青猫は表情切り替えを非表示にし、他の3人へ戻すと本名・読み仮名・4表情を復元します。左右キーの周回も4人に対応します。
- 人数表記・メニュー・キャッシュキーを更新。既存3人の画像、プロフィール、設定画は維持しています。

`character-mode.js`、`character-mode.css`、`index.html`、`gaia-mode-loader.js`、新規SVGとブラウザテスト、および人数・資産URLを検査する既存テスト。
