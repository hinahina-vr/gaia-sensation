# 地図展示の下部UI切り替え

2026-09-07 / ローカル実装。コミット・push・デプロイは行っていません。

## 変更

- `map-dock-motion.js` を追加。MAP 05→06などの展示変更を、確定した展示番号と表示パネルで判定します。
- 入ってくるパネルだけを24〜48px下から480msでせり上げ、2pxの小さな行き過ぎから静かに収めます。高さや文字幅をアニメーションさせず、既存の配置・イベントリスナーを保ちます。
- 標準、リアルタイム、統計、火災、惑星シグナルの下部パネルに共通適用。スマホでは観測パネルだけを動かし、最下部の固定メニューは動かしません。
- 数値更新、地点選択、タイムライン更新、同じ展示の再選択では再生しません。
- 連続切り替え時は前の動きをキャンセル。閉じる操作、画面サイズ変更、非表示、動きを減らす設定への変更でも後始末します。パネル内の操作時は装飾的な動きを即座に止め、ポップアップの座標測定や入力を待たせません。
- `prefers-reduced-motion: reduce` では移動・バウンドなし。物語内の地図操作には適用しません。
- `gaia-mode-loader.js`、`index.html`、キャッシュキー検査を更新。`package.json` に構文検査とブラウザ検査コマンドを登録しました。
- 既存の `check-map-grid-polish-stability.mjs` が古い `gaia-unified-picker-1` を期待していたため、変更前から使われていた現行キーに合わせ、モーションの読み込み順も検査対象に追加しました。
- 前の依頼で作成した青猫の画像・人物設定は維持しています。
