## 追加資料の照合とスコープ保守

基点から既存の `data/gaia-signals.json`、`data/gbif-rights.json`、両package-lock、依存193件とフォント一覧は不変。既存32出典も不変で、新規3件のみ追加。メディアは314→319件、既存314件の内容ハッシュは不変。既存PNG2件の採用・加工説明を更新し、表示用WebP5件を追加した。

案内3画像は [制作記録](MAP_GUIDE_IMAGEGEN_2026-09-10.md)、採用2画像は [指定画像QA](QA_SELECTED_TITLE_ENDING_2026-09-10.md) と変換記録で確認。元画像を削除せず、ロゴや第三者の画像を追加していない。

追加FAO資料の指定引用・年・URL・CC BY 4.0表示・加工主体・非推奨表示をJSONと出典画面で確認。[FAO公式データベース条件](https://www.fao.org/contact-us/terms/db-terms-of-use/en/) を公開時に再確認し、非営利作品での現行表示を対象とする。商業宣伝・推奨の示唆をせず、第三者例外を全指標へ一括適用した承認とはしない。範囲・原本・加工は [FAO出典](FAO_FOOD_SOURCES_2026-09-09.md) に記録。

NASA地域別気温は [GISTEMP公式ページ](https://data.giss.nasa.gov/gistemp/) の出典・取得日・論文引用と照合。既存の提供元の地域格子を同梱し、平滑化・欠測・年平均化・基準期間を表示する。[加工記録](STORY_TEMPERATURE_SOURCES_2026-09-10.md) を維持し、NASAの個別承認を主張しない。

`rights-review.json` の対象ハッシュは現在の素材・出典台帳に追従させる。過去の決定日時・決定理由と `providerPermissionVerified: false` は維持する。今回の一般的公開指示を、未確認の新しい権利リスクの了承に読み替えていない。

最初の `npm run check` は機能・データ検査を通過したが、権利スコープの旧ハッシュで不合格。上記照合後に再実行する。共通ブラウザー試験の展示総数も、新規食料カタログを含む71件へ更新。HTTPS本番の試験では本物の応答ヘッダーを置換しないようテストヘルパーを修正した。

最終コミット、チェック結果、GitHub CI、コミットから新規展開した配信物の全blob照合、デプロイID、実配信HTTPとPC／スマホ幅のブラウザー試験を `artifacts/release-story-temperature-20260910/` に記録する。公開候補内へ試験出力・node_modules・原資料を混ぜず、デプロイは検証済みコミットの同じ展開物を使用する。本記録の作成時点で未実施の公開工程を合格とは扱わない。

実装コミット `10f228f` 後に、追加素材5点のGit初出日時を実履歴から再生成した。続く台帳保守は画像・ランタイムを変更しない。最終 `npm run build:release` は権利ゲート・全体検査・dry-run Workerビルドまで終了コード0（`build-release-final.log`）。センサーtypecheckとローカルPagesの22項目も合格。Wrangler設定ディレクトリへの制限で初回起動に失敗した記録は残し、権限を得て同じ検査を再実行した。

気温デモのPC（地点・年代・保存・読込・台本の実ダウンロード）、選択画像のPC／スマホ、表情直接表示のスマホを最終ランタイムで再確認して合格。全体Chrome試験は71展示・毎回の案内・世界／日本タブの実操作を含む現仕様へ同期。`contest-final-v3` は全機能・復旧検査と59.88fps／55fps基準を通過したが、外部読み取りへのネットワーク拒否4件によりコマンド全体は不合格。この環境失敗を隠さず、ネットワーク許可で同一試験を再実行し、最終結果を別ディレクトリへ保存する。

スマホはChromeの画面・タッチ模擬。物理端末、Safari/Firefox、実機センサー、全編の通読、外部AIへの実送信は今回の確認外。通常STORYの短い横画面で会話欄が立ち絵の顔に重なる既知残件は未修正（今回の気温デモ内と指定エンディングの短横画面は個別検証済み）。修正には長文改ページと保存位置を含む調整・回帰が必要。
