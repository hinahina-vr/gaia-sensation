# センサーヘッダーの重なり修正

## 依頼・再現・変更

ユーザー原文：「かぶってる」。添付画像の上部メニューに「センサーガイド」が重なる問題を対象とした。

変更前の1440px／832px幅のログイン画面で、接続ガイド・利用条件・地図へ戻るにガイドボタンが重なることを再現。音量ボタンも「地図へ戻る」に重なっていた。原因は、ヘッダー内のナビゲーションに対してガイドと音量だけが別々の固定座標で配置されていたこと。

- `sensors/index.html`：ヘッダー内にガイド・音量の配置枠を追加し、変更資産のキャッシュキーを更新。
- `sensors/sensor-platform.js`：ガイドの設置先をbody直下からヘッダー内の専用枠へ変更。API・アカウント・登録・観測処理は変更していない。
- `sensors/sensor-header.css`：センサーページだけに適用する配置規則。ガイドと音量を通常のレイアウトに戻し、1400px以下ではナビを別段にする。760px以下で音量を開く場合は独立した段を確保。公開地図とテレメトリーの上端もヘッダーの高さに合わせる。
- `sensors/sensor-audio.js`：パネル外を押した際の折り畳みをpointerdownからclickのcapture段階に変更。配置が戻っても押したボタンのクリックが空振りしないようにした。90msの押下で中間版の症状を再現してから、同じ操作で確認。
- `sensors/sensor-map-ui.css`：短い横向き画面で一覧タブがズームの「−」に重なることも確認したため、この条件だけ既存の小型一覧ボタンと同様の配置にした。横向きの公開地図はコンパクトなヘッダーを維持し、地図操作ボタンの領域を確保。

対象版はHEAD `9fbd901b68faebaf6148db6e18cdbcb50fa1c778` 上の未公開作業ツリー。既存の未コミット変更を保持。コミット・push・デプロイはしていない。
