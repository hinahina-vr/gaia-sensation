# QA — 2026-09-09 終了画面のボタン先行発光

## 原因と変更

「星々の放課後 / APEIRONCENE」の「世界とつながる」ボタンが表示される前に、その位置だけ光る症状を修正。

終了画面は1.8秒でフェードインするが、従来は表示開始の次のフレームにボタンへ自動フォーカスしていた。地図用コードが読み込まれている場合、フォーカスで起動する共通の光は `body` 直下の独立レイヤーに描かれ、終了画面の透明度・ぼかしの影響を受けないため、光だけ先行していた。

- `true-end-mode.js`：登場アニメーション中は終了画面を `inert` にし、見えないボタンへのポインター操作・フォーカスを止める。実際のアニメーション完了を待ち、次の描画フレームで操作と自動フォーカスを有効にする。固定時間のタイマーは追加していない。
- 動きを減らす設定ではアニメーションがないため速やかに操作可能になる。待機中に画面が破棄された場合はフォーカスを移さない。
- `gaia-mode-loader.js`／`index.html`：キャッシュ識別子を更新。
- `scripts/check-true-end-finale-glint-browser.mjs`／`package.json`：再現・回帰試験を追加。
- ボタンの外観、表示後の光、終了時の白いフェード、台詞・台本データ・保存形式、前回修正したWebGLのフェード処理は変更していない。
