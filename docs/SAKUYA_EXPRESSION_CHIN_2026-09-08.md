# sakuの表情サムネイル — あご位置の修正

ユーザーの画像で、左端の通常表情だけあごが上がって見える症状を再現した。
対象はキャラクターページ内の丸い表情選択サムネイル。元PNGや立ち絵は変更していない。

## 原因と変更

- 左端の通常表情と右端の心配表情は、元画像1024×1536のあごの高さがどちらもy=270。
- 選択中の円に `translateY(-2px) scale(1.04)`、中の全身画像に `scale(1.025)` が重なり、画像中央を基準に拡大されて顔が持ち上がっていた。
- 3840px画面で、左端選択時は右端より6.783 CSS px上。右端選択時は逆に右端が上がることも再現した。
- `character-mode.css` でsakuの表情サムネイルの位置・拡大率を固定。右側の通常時の切り抜きを基準に、選択・ホバー・フォーカスでも動かさない。枠・明るさによる選択表示は維持。
- `gaia-mode-loader.js` と `index.html` のキャッシュ識別子を更新。

## 検証

`node scripts/check-sakuya-expression-alignment-browser.mjs http://127.0.0.1:4447 --record` で変更前を再現。
同コマンドから `--record` を外して修正後を検証する。

- **合格：3840・1440・390・320px、各4表情の計16状態、実行時エラー0。** 最終キャッシュ識別子を含む版で再確認。
- 左端と右端のあごの表示座標、クリック、選択の一意性、ホバー・キーボードフォーカスでの位置不変、戻る操作を検証。
- レポートと比較画像: `artifacts/sakuya-expression-alignment/`。
- `regression-report.json` に検証対象のCSS・ローダー・HTMLのSHA-256を記録。
- `npm run check` 合格。

ローカルChromeの検証。実機スマホ・Safari・公開環境での確認ではない。push・deployは行っていない。
