# タイトルから物語へ：白いプロローグ

依頼受付：2026-09-09。検証は2026-09-10 JSTまで継続。対象は `cdc82c8ffd4fee607bd2d838ec3157b7095952d3` を祖先とするローカル作業ツリー。先行する展示・物語・記録ドックの変更を保持し、コミット・push・デプロイは行っていない。

## 依頼と実装

原文：「タイトル画面から物語始めるときにオープニングっぽいの差し込みたい」「いまBGMがフェードアウトするの短いんでフェードアウトの尺をのばしたい」。指定された白化1.2〜1.5秒、8行のプロローグ、最後の余白、潮風とざわめき、第1話の入口への着地を対象とした。

- タイトルの「物語を始める」にだけ挿入。直接 `/story`、探索画面の物語入口、保存した続きの読込には挿入しない。
- 全画面を白 `#FFFFFF` に1.35秒でフェード。文字は明朝体のスレートグレー `#647581`。指定8行は句読点を含めてそのまま使う。
- タイトルBGMは2.1秒の滑らかなフェードアウト。UI音も減衰させ、白い文章表示中の新たな操作音を抑制する。音量・ミュートの保存値や別の場面のミックス設定は上書きしない。
- 文章は1行ずつ1秒のフェード、1.15秒間隔。最後に2.2秒の余白を置き、1.4秒で白いベールを晴らす。短縮ボタンは白化と消音の完了後に使える。
- 潮風と遠いざわめきはオリジナルのWeb Audio合成。録音・人の音声・外部音源・マイクを使用しない。1.8秒で立ち上げ、音量とミュートに追従。最初の段落を離れると減衰し、退出時は停止する。音作りは最初の描画後に小分けして行い、クリック直後の白化を妨げない。
- 入口の背景を白幕の裏で描画してから晴らす。第1話の章カードを重ねず、「海沿いの展示場の入口で、一度立ち止まった。」から本文を開始する。白幕の裏で本文送り・章タイマー・新規保存を進めない。既存の本文・物語ID・書き出し対象の承認済み台本は変更しない。
- 「本編へ」「タイトルへ戻る」、Escape、中断後の再試行に対応。読み込み失敗はタイトルに通知し、失敗したJS/CSSのキャッシュを破棄して同じ画面から再試行できる。白幕を晴らす途中の中断でも、途中まで開いた物語レイヤーと音量を復元する。

## 変更箇所

`story-prologue.js`：演出、文章、合成環境音、モーダル操作・終了処理。

`opening.js` / `opening.css`：タイトル入口との接続、表示、失敗時の復帰。

`opening-audio.js` / `ui-sound.js`：一時的な所有者別のBGM減衰、UI音の減衰。

`novel-mode.js`：背景の事前描画と白幕解除後の本文開始、中断時の復旧。

`scripts/check-story-white-prologue-browser.mjs` を追加し、`npm run check:story-prologue:browser` で再現可能。既存の入口・音・遷移試験は、新しい演出待ちと現行の保存バージョンに合わせて待機条件・fixtureを更新した。
