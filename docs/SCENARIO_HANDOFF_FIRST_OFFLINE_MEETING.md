# 初オフライン対面｜正本確認と立ち絵解禁ゲート

## 結論

05人物関係正本で指定された初対面描写は、現行正本にすでに反映されている。主要な補強は `116b1ab` と `2df9f5a` の履歴で確認できた。新しい台詞を重ねず、現行本文を確定稿として扱う。

## 変更前→確定稿

旧い短縮稿では、中央入口の集合と青りんごの撮影が早く進み、三人が文字だけで知っていた相手へ初めて会う戸惑いが不足していた。確定稿では次の段階を置く。

1. `first_meeting_promise_014`〜`_054`: 会うか迷い、サクヤが文を二度消し、三人が顔を知らないことと誤認の不安を言葉にする。
2. `first_meeting_hall_001`〜`_030`: ミズハとアマネが顔ではなく青りんご、位置情報、学内チャットの現在投稿を照合する。
3. `_031`〜`_033`: 二人が表示名を声に出し、顔・声・表示名を初めて結び付ける。
4. `_034`〜`_040`: アマネは未使用の消毒シートを戻し、ミズハは握手へ出しかけた手を髪へ逃がす。
5. `_041`〜`_066`: サクヤが別入口から遅れて到着し、青りんごを指して二人を一人ずつ呼び、返答と声で認知する。
6. `_067`〜`_077`: サクヤが写真を頼み、三人は手だけを近づけ、撮影後の画面をのぞくとき初めて肩が触れる。
7. `festival_walk_001`以降: 七時間後には「さん」が取れ、声で呼び止められるが、長年のオフライン友人の距離にはしない。

## 時系列フラッシュバックと到達フラグ

- 時系列が過去へ戻っても、一度完了した各人物の対面到達フラグは保持する。ただし過去の未対面sceneを再生している間は、フラグが立っていても大型立ち絵を表示しない。
- NEW GAMEでは三人すべて未到達へ戻す。
- SAVE/LOADでは人物別の到達フラグを保存・復元する。
- 未到達分岐や巻き戻しでは、その人物の完了stepをまだ表示していなければ解禁しない。既読LOG、学内チャットを開く、投稿を受信する、小型avatarを見るだけでは解禁しない。
- `first_meeting_promise`以前、および`first_meeting_hall_032`より前は、ミズハとアマネの大型立ち絵を出さない。`first_meeting_hall_067`より前はサクヤの大型立ち絵を出さない。

## 02監督受入の四条件

- 不安・期待・距離感は、入力削除、三歩の距離、手の逃げ、視線、呼吸、写真で示される。
- 表示名の確認直後にも沈黙と距離が残り、即座に旧友の会話へ移らない。
- ミズハは言葉、アマネは位置と手順、サクヤは視線と写真で確認し、反応をテンプレート化しない。
- 青りんごの撮影と七時間の展示巡りを経て、段階的に会話が短く自然になる。
