## 欠測と比較上の注意

- 沖縄県の人口移動・住宅着工は1973年から収録。それ以前はそれぞれ19年・22年を `null` とする。
- 気象庁の資料不足値 `]` は参考の数値があっても `null`。今回の湿度6、日照11、降水量2、降水日数1の計20セルが該当する。
- 準正常値 `)` は数値と品質フラグを保持する（今回の4系列には該当なし）。
- 欠測を0・補間値へ置き換えない。年スライダー上には欠測年を残し、統計計算からは除外する。
- 気象は県全域の平均ではない。移転や測器変更を補正していない。特に日照の1986〜1990年の測器変更を地図・分析の両方に表示する。
- 地図の色の範囲は各指標の全期間・全47対象で固定。すべての長期展示で約1.05秒ごとに年を進める。手動選択後は2倍の間隔を置く。
- 分析は選択県・観測地点の年系列。横軸は年で、年の行を都道府県として順位・集中・移動先に読み替えない。課題探索は仮説で、因果推定・将来予測ではない。
- 読込失敗時に古い月次値を年次と表示しない。値は欠測、期間は「—」、分析ボタンは無効になる。

## 再生成・検証

生成器は `scripts/build-prefecture-annual-history.py`。Python 3、`openpyxl`、旧 `.xls` 用の `xlrd` が必要。原本は `artifacts/annual-history/sources` にURLハッシュ名でキャッシュされる。生成器のURLと最終年は固定で、自動で新年度へ更新しない。

```sh
python scripts/build-prefecture-annual-history.py --build
# xlrdを隔離ディレクトリに置く場合は --xls-deps <directory> を追加
npm run check:annual-history
npm run check:annual-history:browser
npm run check:statistics-visual-picker:browser
```

生成時に人口移動の全国差引0、住宅着工の公式全国計との一致、宿泊の全国計との丸め誤差範囲内の一致を検証する。年・都道府県の並び、系列の重複、未認識のセルはエラーにする。3つの社会統計の原本SHA-256と出典・対象集団、気象の47地点URLと品質フラグをJSONに保存する。

`check:annual-history` は10系列×47対象の470分析について、平均・件数・欠測除外・時間軸の課題探索を検証。ブラウザ検証は1440px/390pxで全展示の始点・中間・終点、実ボタンからの分析、欠測、キーボードと再生、読込失敗を確認する。グラフィカルな分析メニューは1440px/390px/320pxで7目的・26手法とキーボード操作を確認する。

主な実装：`estat-exhibit-catalog.js`（表示定義）、`estat-exhibits.js`（年スライダー・出典・分析データ）、`statistics-discovery.js`（時間系列の課題探索）、`statistics-menu.js`（分析のSVG図解カード）。原本Excelは閲覧・抽出のみで変更しない。
