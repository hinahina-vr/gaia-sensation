# GAIA SENSEWARE Beyond｜SÆLIVA CANON

状態：CANON / Beyond実装・演出・追加台本の共通参照

この文書は、二百七十万年後の世界と、画面に現れる星間共感記法
`SÆLIVA（セイリヴァ）` の確定設定を定義する。

## 1. SÆLIVAとは

SÆLIVAは銀河共通の「母語」ではない。
異なる生物、機械知性、海、森、恒星大気が、それぞれの感覚を
一つの人間的意味へ潰さず、関係と状態だけを共有するための共感記法である。

名称は `SÆL`（感じ取る）と `IVA`（異なるまま関係する）の複合。
地球語転写では `SÆL·IVA` と分解できるが、言語名は `SÆLIVA` と綴る。

成立の直接原因は、星間文明が「完全翻訳」を断念したことにある。
ある存在の痛み、千年単位の潮汐、磁場を色として感じる知覚は、
同じ語へ翻訳した瞬間に重要な差異を失う。そこで内容そのものではなく、
誰が、何を、どの確度で、どの範囲へ伝えたかを共有する記法が発達した。

SÆLIVAは支配言語ではない。各世界の母語・信号・感覚は残り、
SÆLIVAはそれらの間に置かれる薄い接続層としてだけ働く。
この原則はBeyondの文明観「異なるまま感じられる範囲を増やす」と一致する。

## 2. 表記と文法

- 地球の画面に見える字形は、未来の多感覚記法をラテン字へ落とした転写。
- 語順は修飾語が先、中心概念が後。所有よりも関係を優先する。
- 中黒 `·` は、二語が上下関係なく一つの状態を作る結合記号。
- `·EN` は観測済み・確定・登録済み。
- `·AI` は未決定・開放・継続中。
- `·IR` は複数ではなく、中心を持たず分散している状態。
- 数値、固有名、発掘物の型番は改変しない。翻訳より来歴保存を優先する。
- 発音は母音を省略せず、強勢で命令と疑問を作らない。状態接辞が確度を担う。

## 5. 物語上の制約

- ルウはSÆLIVAを母語とは呼ばない。ルウ自身にも単一の母語はない。
- 三人とVISITORに聞こえる日本語は接触身体による局所翻訳。
- 画面のSÆLIVAは未来文明が直接送った文章ではなく、接触身体が選んだ転写。
- `·EN` が付かない推定を、SOURCEや確定史実として扱わない。
- `·AI` は欠陥ではなく、次の観測者へ選択を残す肯定的な未決定を表す。
- SÆLIVAを銀河帝国、単一意識、完全翻訳の証拠にしない。
- 地球由来の名称 `GAIA SENSATION`、`Beyond`、人物名、`ESP32` は保存対象として置換しない。
- ESP32の演算能力を未来文明の「玩具」級として扱わない。K2.7文明の尺度では計算機として比較する最小目盛りにも届かず、現代人にとっての素粒子一つよりさらに小さい。ただし価値の焦点は性能差ではなく、観測し、記録し、離れた場所へ渡そうとした不可逆な行為に置く。

## 6. 演出原則

SÆLIVAは初見で完全には読めなくてよい。ただし同じ語根は同じ概念へ反復し、
観客が `SÆL`、`MIR`、`KAR`、`·EN`、`·AI` の役割を画面の流れから推測できるようにする。
日本語セリフまで置換せず、異質さはシステム表示の層に限定する。

最終表示 `NÆI MIR: REA·AI` は「次の観測は未定」ではなく、
「次を決める権利がまだ閉じられていない」というBeyondの結論である。
