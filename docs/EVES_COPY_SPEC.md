# E.V.E.S.｜確定コピーと表示条件

## 画面の役割

この画面は、このプレイで実際に行った二つの選択を、選んだ順に確認する画面である。最後に確定した選択を一件だけ取り消し、その選択画面からやり直せる。

人物診断、得点表示、正解ルート、別エンディング一覧ではない。公開版や次の来場者の初期状態を書き換える画面でもない。

## 最初に見えるコピー

| 表示箇所 | 主表示 | 副表示・補足 |
|---|---|---|
| 画面タイトル | **これまでの選択** | `E.V.E.S.` は小さな装飾表記に下げる。`Epistemological Variant Evolution System` と `BRANCH ARCHIVE` は表示しない。 |
| 冒頭説明 | **このプレイで行った二つの選択を確認し、最後の選択からやり直せます。** | **箱は選択する場所とその結果、線は選べる内容と進む順番を表します。** |
| 進行見出し | **選択の進み具合** | `CURRENT POSITION` は表示しない。 |
| 機能補足 | **得点や性格診断を表示する画面ではありません。** | 常時表示が窮屈なら、冒頭説明の直後に一度だけ表示する。 |

冒頭の主表示だけで、次の三点を読める順に並べる。

1. 何の画面か――このプレイの選択を確認する画面。
2. 何が記録されているか――最終画面の表示方法と、次へ持ち帰りたい姿勢。
3. 何ができるか――最後の選択を一件だけ取り消してやり直す。

## 選択の進み具合

| 状態 | 表示 |
|---|---|
| 選択前 | **0 / 2｜まだ選択前です** |
| 選択1だけ完了 | **1 / 2｜最終画面の表示を選びました** |
| 選択2まで完了 | **2 / 2｜二つの選択が完了しました** |

現在いる箱には、英語の状態名ではなく **現在** と表示する。「現在」は物語の章ではなく、二つの選択の進み具合を指す。

## 分岐図のコピー

分岐図は左から右へ、次の順で表示する。

| 種別 | 主表示 | 選択・結果の表示 |
|---|---|---|
| 開始 | **プレイ開始** | なし |
| 選択1 | **選択1｜最終画面に何を表示するか** | **本人から届いた記録だけを表示** / **本人の記録と生成した部分を分けて表示** |
| 選択2 | **選択2｜次へ持ち帰りたい姿勢** | **1〜3件選んで進む** / **何も選ばず進む** |
| 結果 | **今回の選択結果** | 選択1と選択2の結果を具体的に組み合わせて表示する。 |

結果の表示例:

- **本人から届いた記録だけを表示／姿勢を2件選択**
- **本人の記録と生成した部分を分けて表示／何も選ばずに進んだ**

姿勢を選んだ場合は、`state.reflectionIds.length` により **1件／2件／3件** の件数だけを表示する。選んだ文、選択ID、内部属性、得点、演出系統は表示しない。

四本の線は、選択肢のつながりと進む順番を示す。第二選択後に複数の線が明るくなる現行表示は「第二選択まで完了した範囲」であり、実際に通った一本を示すものではない。したがって、**明るい線が選んだ経路**とは説明しない。実際の到達結果は、結果の箱に付く **現在** または到達済み表示で読ませる。

## 選択した内容

| 表示箇所・状態 | 確定コピー |
|---|---|
| 見出し | **選択した内容** |
| 見出し補足 | **このプレイで選んだ内容を、選んだ順に表示します。** |
| 選択なし | **まだ選択はありません** |
| 選択なし補足 | **物語を進めると、ここに選んだ内容が表示されます。** |
| 一件目の番号 | **選択1** |
| 一件目の分類 | **最終画面の表示** |
| 一件目・本人記録のみ | **本人から届いた記録だけを表示** |
| 一件目・生成部分も開示 | **本人の記録と生成した部分を分けて表示** |
| 二件目の番号 | **選択2** |
| 二件目の分類 | **次へ持ち帰る姿勢** |
| 二件目・選択あり | **次へ持ち帰りたい姿勢を1件選んだ** / **2件選んだ** / **3件選んだ** |
| 二件目・未選択 | **何も選ばずに進んだ** |

`EVOLUTION LOG`、`NO VARIANT YET`、`VARIANT 01 / 02`、単独の「観測姿勢を選ぶ／選ばない」は使用しない。同じ「選ぶ」が上下に並び、何を選んだか分からない表示に戻さない。

## 最後の選択をやり直す

ボタンの主表示は **最後の選択をやり直す** とする。「ひとつ前の分岐へ戻る」は使用しない。

| 現在の状態 | ボタン | ボタン直下の補足 |
|---|---|---|
| 選択0件 | 無効 | **まだやり直せる選択はありません。** |
| 選択1だけ完了 | 有効 | **「最終画面の表示」の選択を取り消し、その選択画面へ戻ります。物語の既読記録は残ります。** |
| 選択2まで完了 | 有効 | **「次へ持ち帰りたい姿勢」の選択と結果演出を取り消し、その選択画面へ戻ります。「最終画面の表示」の選択は残ります。** |

選択2まで完了した状態では、`reflectionIds` と `resultTone` だけを消す。選択1の `editorialChoice` は残す。選択1だけ完了した状態では、`editorialChoice`、`reflectionIds`、`resultTone`、`evesRoute` を消し、同じ選択画面へ戻る。どちらも `readStepIds`、`reachedSceneIds` など、既読LOGや到達済みsceneは消さない。

## SOURCE / DERIVEDを併記する場合

英語は装飾的な副表記に限る。同じ場所で、必ず次の日本語を主表示する。

| 副表記 | 主表示 |
|---|---|
| `SOURCE` | **本人から届いた記録** |
| `DERIVED` | **観測から計算・生成した内容** |

サクヤ本人から届いた文と、ミズハが生成した部分は統合しない。生成した内容には、生成・選定した責任者と本人未確認である事実を残す。

## 表示条件

| 条件 | 表示する内容 |
|---|---|
| `editorialChoice` なし | 進み具合0/2、選択履歴なし、やり直し無効 |
| `editorialChoice` あり・姿勢選択未完了 | 進み具合1/2、選択1の具体的な内容、やり直し対象は選択1 |
| `reflectionIds.length` が1〜3 | 進み具合2/2、選択2は選択件数を表示、やり直し対象は選択2 |
| 姿勢を選ばず完了 | 進み具合2/2、選択2は「何も選ばずに進んだ」、やり直し対象は選択2 |
| 結果ノードが現在 | 該当する箱に **現在** を表示 |
| 結果ノードが到達済み・現在ではない | 到達済みであることだけを表示し、現在表示と混同させない |

## 五秒確認の受入基準

画面上部と現在の箱だけを見て、初見プレイヤーが次を答えられること。

1. これは何の画面か――このプレイで行った二つの選択を確認する画面。
2. 何が記録されているか――最終画面の表示方法と、次へ持ち帰りたい姿勢。
3. 箱と線は何か――箱は選択する場所と結果、線は選べる内容と順番。
4. 「最後の選択をやり直す」と何が起きるか――最後の一件だけ取り消し、その選択画面へ戻る。
5. 現在どこにいるか――0/2、1/2、2/2と、**現在**の付いた箱で分かる。

コピーの読み合わせでは、詩的・専門的な言い換えを足さず、この五つが明示されているかだけを判定する。
