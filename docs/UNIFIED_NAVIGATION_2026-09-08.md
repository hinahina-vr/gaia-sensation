# 「戻る」「タイトル」の共通化 — 2026-09-08

## 対象と仕様

ローカル作業ツリーのみ。push・deploy・配布ZIP作成は行っていない。
ベースコミット: `63ec6ffdb495256fde6ad1e58c7c963954c741c3`。
共通CSSの版: `gaia-unified-navigation-1`。
HTMLから読み込むローダーと変更した本体のキャッシュ識別子: `gaia-hardening-1-unified-navigation-1`。

- ページを離れるボタンは左上16px（ノッチ等のsafe areaが大きい場合はそちらを優先）。
- PC・スマホ共通で高さ44px、最小幅88px、角丸12px、文字12px。
- 文字数によって幅のみ伸びる。省略やスマホだけの小文字化はしない。
- 紺色の背景・枠・影・左向き矢印・ホバー・キーボードフォーカスを共通化。
- 対象: 入口の「タイトル」、地図、音楽、キャラクター、宇宙、物語、センサー各ページ。
- 登録・詳細画面内の「マイセンサー」など、同じページの中に置く補助ボタンは文書内の位置を維持し、外観を共通化。スクロール先への移動とページ退出を混同しない。

## 再現と回帰テスト

`npm run check:navigation:browser` でローカルのQAサーバーとChromeを起動する。
画面の存在確認だけでなく、実際の描画座標、寸法、フォント、色、矢印、ヒット対象、ホバー、クリック・Enterでの戻り先を検査する。
出力は `artifacts/unified-navigation/`。`regression-report.json` と幅別レポートには対象ソースのSHA-256、ベースコミット、検証結果を記録する。

検証幅は1440・1024・390・320px。入口・地図・音楽・キャラクター・宇宙・物語に加えて、センサーの地図・接続ガイド・利用条件・一覧・プロフィール・登録・詳細を対象とする。
キャラクターと長いセンサーページのスクロール後も位置を確認する。文字数の多い「マイセンサー」は、同じ高さ・文字サイズのまま横幅が伸びることを検査する。

変更前の再現には `--baseline` を指定する。HEADのナビゲーションHTML・本体JS・センサーページHTML/CSS/JSをブラウザーへ読み取り専用で配信し、作業ツリーを書き戻さない。周辺アセットは作業ツリーを利用するため、公開環境そのものの検証ではない。
