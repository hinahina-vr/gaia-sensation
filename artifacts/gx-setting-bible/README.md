# GAIA SENSEWARE — GX Visual Setting Bible

ImageGenで作成した、実装前の世界観検討用ビジュアルです。
採用済みのキャラクターデザイン「07」を基準に、ミズハ・アマネ・サクヤの三人と、Gaia Transformationの物語構造を10枚へ展開しています。

## Sheets

1. `01-three-ecologies-character-master.png`  
   三人の基準設定画。ミズハ＝生態・身体、アマネ＝社会・技術、サクヤ＝精神・文化。
2. `02-first-meeting-zushi-coast.png`  
   オンライン大学の三人が逗子の海辺で初めて会うプロローグ。
3. `03-gaia-senseware-installation.png`  
   公開データを10の感覚器官へ変換する、作中の展示空間。
4. `04-life-earth-coevolution.png`  
   生命が地球を変え、変わった地球が生命を変えてきた共進化史。
5. `05-anthropocene-planetary-force.png`  
   人類が地球規模の力を持った「人新世」のスケール感。
6. `06-ai-earth-coevolution.png`  
   AIを支配者や救世主ではなく、分散した地球の器官として描く案。
7. `07-three-ecologies-world.png`  
   生態・社会・精神の三つのエコロジーが重なる生活世界。
8. `08-old-os-to-gx.png`  
   自然・社会・技術を切り離す古いOSから、循環と共創のGXへ移る対立構造。
9. `09-next-stage-civilization.png`  
   人間、他の生命、人工システムが共進化する現実寄りの次段階文明。
10. `10-final-keyvisual.png`  
    観客が第四の共創者として信号を加える、作品全体の最終キービジュアル案。

## Common generation direction

- 採用済み07案の顔、等身、服装、水彩・色鉛筆の手描き感を維持する。
- 約6〜6.5頭身。ちびキャラ、過剰なフリル、性的表現を避ける。
- ミズハは深い水色、アマネは淡い空色、サクヤは灰桜と温かい茶色で区別する。
- ガラス的なAIアニメ塗り、死んだ目、過剰な虹色、サイバーパンク表現を避ける。
- 地球を守られる完成品、人類を外部の救世主として描かない。
- 技術、生命、文化が一つの地球システムの中で関係を編み直す構図にする。
- 画像内テキストは管理番号 `GX / 01`〜`GX / 10`だけに限定する。

これらは設定検討用で、現時点ではWebサイトへ組み込んでいません。
