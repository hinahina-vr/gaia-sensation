## 地球を知ることから、自分の物語を生きることへ。

『惑星の放課後』は、公開データとして保存された地球の変化を、光・色・動き・音へ翻訳する観測体験と、海辺の展示ブースから始まる出会いを描く、展示参加型ヴィジュアルノベルです。

宇宙から見下ろす衛星の記録と、街角の日陰や机の上で測る、小さなセンサーの値。その間には、誰かの暮らしがあります。遠い場所の気温や海流を、画面の向こうの出来事で終わらせず、いま自分が立っている場所へつなぎ直したい。その思いから、地球を観測する展示と、人が出会い、言葉を交わす物語を、一つの作品にしました。

ZEN大学の講義で出会った、地球と生命の共進化、データの読み方、人間が物語を紡ぐ意味。それらを知識の紹介にとどめず、登場人物と同じ景色を眺め、気になったことを自分の手で確かめる体験へ。71の地図展示と学生たちの物語を行き来しながら、途方もない惑星の時間と、放課後の何気ない会話を重ねていきます。

そして、作品の奥にあるのは、**「世界について分かること」と「自分がどう生きるか」は、同じではない**という問いです。データやAIが未来の可能性を示しても、その意味を受け取り、歩き出すのは自分自身。その主体性を取り戻すための構想を、本作では「神話製作機械」と呼んでいます。観測の根拠は確かめられるように、人生の意味づけは人に残す。世界を知ったあとに、どんな物語を生きるのか――その続きを、遊ぶ人へ託す作品です。

## まず体験する

1. 通常の入口で言語と音の有無を選択します。オープニング後に物語かデータ探索へ進めます。
2. 地図をすぐ見る場合は [展示01](https://gaia-senseware.pages.dev/#world-01) へ。地図を移動・拡大し、観測点を選びます。
3. 「展示メニュー」で世界16展示／日本55展示を選ぶか、「前の展示へ」「次の展示へ」で巡ります。PCではメニューのホバー／フォーカスでも開けます。
4. 年代などのスライダー、出典ボタン、「統計分析」で、値と変化の読み方を確認します。スマホでは「読み方・凡例」「操作」に機能をまとめています。
5. 自動で巡る場合はクルージングモードへ。スライダー終端の3秒後、または地点を5秒ずつ最大5地点巡った後に次へ進み、全展示をループします。

「自動表示」は現在の展示内の再生、「クルージング」は展示をまたぐ巡回です。読込中・ガイド表示中などは進行を待ちます。

### 分析とAI

対応する展示では「統計分析」からグラフ、観測データ、分析結果と注意点を確認できます。解析はブラウザ側で行い、AIを使わなくても閲覧・統計分析できます。

AIへの質問は任意です。利用者自身のAPIキーと送信先設定が必要で、確認後に選択データ等を指定先へ送信します。キーをリポジトリに記載しないでください。AIの回答は観測結果の保証ではありません。
