## 原本と表示用ファイル

3枚のPNG原本は1672×941で、生成出力とSHA-256が一致します。[selection.json](selection.json)に生成ファイル名、原本・WebPの寸法、容量、SHA-256を記録しています。

`scripts/encode-selected-opening.mjs`で全画角のWebPを作成。初期画面の保守的な1MB上限を維持するため、初対面は品質84、人物紹介は品質92です。通常表示1672×941と低メモリー端末向け834×469を用意し、画像そのものは切り抜かず、必要な表示位置のみCSSで調整しています。WebPは非可逆圧縮であり、PNGとの画素完全一致を意味しません。

```powershell
node scripts/encode-selected-opening.mjs <生成画像の保存ディレクトリ>
```
