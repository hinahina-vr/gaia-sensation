## Display treatment

MAP 30 uses the image's luminance as a translucent cloud-shape mask. Shader opacity and brightness respond to the separate Open-Meteo model data; slow displacement is decorative, not a satellite time series. The original JPEG is not edited. The layer is labelled as reference imagery and must never be presented as the current satellite cloud distribution. Point values, source names, and JST times continue to refer to Open-Meteo, not this reference image.
